# Визуальные материалы и лицензии

Цель — не украсить страницу, а дать читателю возможность **проследить
изменение состояния системы**. Для каждого внешнего asset фиксируем автора,
прямой URL, лицензию, дату проверки и учебную функцию.

объяснения, а не декоративная вставка. Перед редактурой подраздела сравниваем
несколько учебных источников, выбираем наиболее ясную последовательность и
переносим вместе с ней подходящие слайды, таблицы или анимации. Собственный текст
соединяет выбранные фрагменты и поясняет их по-русски.

## Пять повторяемых интерактивных шаблонов

1. **Matrix stepper** — входные tensors → одна операция → новые shapes и числа.
   Подходит для QKV, RoPE, normalization и quantization.
2. **Token-flow router** — tokens → logits → top-k → очереди experts → merge.
   Подходит для MoE, routing и load balancing.
3. **Timeline** — prefill → decode steps → рост KV cache → memory/latency.
   Подходит для inference и speculative decoding.
4. **Pipeline с failure points** — ingestion → retrieval → reranking → context →
   answer, с метрикой и артефактом на каждом ребре. Подходит для RAG и agents.
5. **Compare mode** — одинаковый input проходит через две архитектуры, а справа
   показываются compute, memory, state и quality assumptions.

### Manifest импортированных материалов по ML Systems

Каталог `00 Учебник/Assets/Figures/curated/ml-systems/` содержит собственный
`assets.yml`. Каждое изображение в каталоге и его подкаталогах обязано иметь в
этом manifest ровно одну запись со следующими полями:

- `file` — путь к файлу относительно каталога `ml-systems/`;
- `author` — автор или организация, выпустившая исходный материал;
- `source_url` — GitHub `blob`-ссылка, закреплённая на полном 40-символьном
  commit SHA;
- `commit` — тот же полный commit SHA отдельным полем;
- `license` — лицензия исходного материала;
- `modified` — менялось ли изображение после импорта;
- `used_in` — непустой список учебных страниц, где используется изображение.

Текст внутри импортированного изображения сохраняем на языке источника, а
русское объяснение даём рядом в учебной странице. Перевод, замена или
локализация текста внутри изображения считается модификацией: для такой версии
ставим `modified: true`, не теряя ссылку на закреплённый оригинал.

Для открыто опубликованного учебного материала отсутствие отдельно указанной
лицензии рисунка не блокирует включение в Bookvar: владелец репозитория разрешил
такое некоммерческое переиспользование. В реестре в этом случае честно пишем,
что отдельная лицензия не указана, и обязательно сохраняем автора, исходную
страницу, прямую ссылку и сведения о модификациях. Собственную иллюстрацию делаем
только тогда, когда готового качественного объяснения после поиска не найдено.
