# Source-first ведомость тем 01–18

Это сравнительная редакционная ведомость, а не публикуемая глава. Для каждого
фрагмента она фиксирует рекомендуемый позвоночник текста, альтернативные
источники, педагогические ходы и готовые иллюстрации, которые можно перенести с
точной атрибуцией.

## 1. Векторы, матрицы и тензоры

### Основной источник

- **D2L, §2.3 Linear Algebra:**
  <https://d2l.ai/chapter_preliminaries/linear-algebra.html>. Брать порядок
  `scalar → vector → matrix → tensor`, shapes, reduction, dot product,
  matrix–vector и matrix–matrix multiplication, broadcasting. Не начинать с
  абстрактного определения тензора.

### Дополнительные источники

- **Stanford CS231n, Linear Algebra Review:**
  <https://cs231n.github.io/linear-algebra/>. Полезны соглашения о строках и
  столбцах и объяснение matrix multiplication как параллельных dot products.
- **D2L, Appendix §22.1 Geometry and Linear Algebraic Operations:**
  <https://d2l.ai/chapter_appendix-mathematics-for-deep-learning/geometry-linear-algebraic-ops.html>.
  Использовать для геометрии нормы, угла и проекции.

### Что адаптировать

Один объект формы `[B, T, D]` нужно последовательно прочитать как набор чисел,
матрицу признаков одного примера и пакет последовательностей. На нём удобно
показать три среза и одну операцию по последней оси. Затем связать индексы в
формуле с формами в коде.

### Готовые визуалы

- Иллюстрации matrix multiplication и tensor axes из D2L §2.3.
- Схема матричного linear classifier из CS231n.

Не рисовать собственную схему осей, если готовая иллюстрация D2L выполняет ту же
работу.

## 2. Производная и градиент

### Основной источник

- **D2L, §2.4 Calculus:**
  <https://d2l.ai/chapter_preliminaries/calculus.html>.
- **D2L, §2.5 Automatic Differentiation:**
  <https://d2l.ai/chapter_preliminaries/autograd.html>.

Сохранить порядок `secant → tangent → partial derivatives → gradient →
automatic differentiation`.

### Дополнительные источники

- **Andrej Karpathy, The spelled-out intro to neural networks and backpropagation:
  building micrograd:** <https://www.youtube.com/watch?v=VMj-3S1tku0>.
- **micrograd repository:** <https://github.com/karpathy/micrograd>. Это лучший
  источник для reverse mode, ручных локальных производных и topological
  backward pass.
- **Yandex ML Handbook, «Матричное дифференцирование»:**
  <https://education.yandex.ru/handbook/ml/article/matrichnoe-differencirovanie>.
  Использовать для русской системы обозначений и перехода к дифференциалам.

### Что адаптировать

Взять из micrograd один сквозной граф вида `a,b → c=a*b → d=c+… → L`. Сначала
вычислить локальные производные вручную, затем провести gradient signal назад.
После scalar example перейти к vector–Jacobian product.

### Готовые визуалы

- Tangent/secant graph из D2L §2.4.
- Вычислительный граф из открытой лекции micrograd.
- Figure 17 из статьи Yandex для reverse propagation.

## 3. Вероятность, likelihood и логарифм

### Основной источник

- **D2L, §2.6 Probability and Statistics:**
  <https://d2l.ai/chapter_preliminaries/probability.html>.
- **D2L, Appendix §22.7 Maximum Likelihood:**
  <https://d2l.ai/chapter_appendix-mathematics-for-deep-learning/maximum-likelihood.html>.

Развести event probability, density, random variable, expectation и likelihood
параметра при фиксированных данных.

### Дополнительные источники

- **Yandex ML Handbook, «Вероятностный подход в ML»:**
  <https://education.yandex.ru/handbook/ml/article/veroyatnostnyj-podhod-v-ml>.
- **Jurafsky & Martin, SLP3, Chapter 3 / official slides:**
  <https://web.stanford.edu/~jurafsky/slp3/slides/3_LM_2024.pdf>. Использовать
  chain rule, произведение условных вероятностей и переход к log probabilities.

### Что адаптировать

Одна монета задаёт весь ход: вероятность данных при фиксированном $p$,
likelihood как функция $p$ при фиксированных наблюдениях, максимум likelihood и
логарифм, превращающий произведение в сумму.

### Готовые визуалы

- Probability mass histograms из D2L.
- Слайд SLP3 с chain-rule factorization предложения.
- Слайды SLP3 с log probability и perplexity.

### Дополнительные источники

### Что адаптировать

связывать с предположением о данных и требуемым поведением, а не подавать как
произвольную штрафную формулу.

## 5. Train, validation и test

### Основной источник

- **D2L, §3.6 Generalization:**
  <https://d2l.ai/chapter_linear-regression/generalization.html>. Брать
  population risk, empirical risk и роли train/validation/test.

### Дополнительные источники

- **Stanford CS231n, Neural Networks Part 3:**
  <https://cs231n.github.io/neural-networks-3/>. Разделы Data Preprocessing и
  Hyperparameter Optimization.
- **Yandex ML Handbook:** <https://education.yandex.ru/handbook/ml>. Использовать
  разделы model selection и validation для русской терминологии.

### Что адаптировать

Показать model-selection loop, в котором validation set можно фактически
«переобучить» большим числом решений. Test set открывается один раз после
фиксации pipeline. Нужен отдельный пример leakage при разбиении связанных
объектов: одного пользователя, документа или временного ряда.

### Готовые визуалы

- D2L diagrams train error vs generalization error.
- CS231n coarse-to-fine hyperparameter search plots.

## 14. Autoencoder и VAE

### Основной источник

заменить одну точку на distribution $q(z\mid x)$, ввести prior matching,
разложить ELBO и только после этого объяснить reparameterization. Не начинать с
готовой ELBO без мотивации.

## 16. N-граммная языковая модель

### Основной источник

- **Jurafsky & Martin, SLP3, Chapter 3 and official slides:**
  <https://web.stanford.edu/~jurafsky/slp3/slides/3_LM_2024.pdf>.

Взять chain rule, Markov approximation, count tables, add-k, backoff,

главы.

### Дополнительные источники

- **Karpathy, The spelled-out intro to language modeling: building makemore,
  Part 1:** <https://www.youtube.com/watch?v=PaCmpygFfXo>. Использовать bigram

### Что адаптировать

На одном маленьком корпусе имён пройти `counts → row normalization → likelihood

меняет estimator условного распределения, но не chain rule.

## 17. Word2Vec, GloVe и distributional semantics

### Основной источник

and extrinsic evaluation → bias`. Сохранять последовательность и использовать

### Дополнительные источники

  <https://d2l.ai/chapter_natural-language-processing-pretraining/index.html>.

  and Figure 1:** <https://arxiv.org/pdf/1301.3781>.
- **Pennington et al., GloVe, Sections 2–3 and Figure 1:**
  <https://aclanthology.org/D14-1162.pdf>.

methods. Закончить нужно ограничениями, частотностью, intrinsic/extrinsic
evaluation и bias, а не только арифметикой `king − man + woman`.

### Что адаптировать

Одну строку провести через все стадии tokenizer pipeline. Затем на одном toy
vocabulary выполнить по шагам training algorithms BPE, WordPiece и Unigram.
Отдельно объяснить, что SentencePiece — library/framework, а BPE и Unigram —
алгоритмы модели токенизации.
