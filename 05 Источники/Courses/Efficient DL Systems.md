# Efficient Deep Learning Systems — original course materials

This section mirrors the teaching materials from
[`mryab/efficient-dl-systems`](https://github.com/mryab/efficient-dl-systems)
at commit
[`e632aa89ca9e6638d52e1b686095e7442faffbb0`](https://github.com/mryab/efficient-dl-systems/commit/e632aa89ca9e6638d52e1b686095e7442faffbb0).
It contains the complete course README files, notebooks with code and saved
outputs, homework statements, and all ten slide decks. The material has not
been translated or summarized.

For slide decks, the original PDF is embedded as the primary visual document.
Page-separated text is also included so that the slides can be searched from
Bookvar. Notebook pages preserve Markdown cells, executable code, and outputs
saved in the repository.

The repository is distributed under the
[MIT License](https://github.com/mryab/efficient-dl-systems/blob/e632aa89ca9e6638d52e1b686095e7442faffbb0/LICENSE).
Individual figures embedded in the course may originate from cited external
sources; their attributions remain part of the original slides or notebooks.
