# Machine Learning Visualized — original book and interactive notebooks

This section preserves Gavin Hung's compiled book and the interactive Marimo
pages committed in
[`950f8ec4671c0790cdd867514cc114fea01f5ab0`](https://github.com/gavinkhung/machine-learning-visualized/commit/950f8ec4671c0790cdd867514cc114fea01f5ab0).
The 55-page English book derives and implements gradient descent, linear
regression, K-means, PCA, logistic regression, the perceptron, neural networks,
backpropagation, and autoencoders. The original PDF remains the primary visual
document.
