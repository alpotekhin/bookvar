# Scaling Laws for Reward Model Overoptimization

Работа измеряет расхождение между оптимизируемой моделью награды и отдельной
контрольной моделью при усилении отбора или обучения. Контрольная модель
создаёт обучающие метки для более слабой; это синтетическая постановка,
а не непосредственное измерение человеческого качества.
