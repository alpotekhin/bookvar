их побайтовое сравнение дало совпадение. BSD-3-Clause прочитана полностью.

| Место | Изменение | Конкретная проверка |
|---|---|---|
| Разбиение по группам | Добавлена исходная схема GroupKFold; объяснены полосы групп и классов | Все группы целиком по одну сторону каждого разбиения, каждый объект проверен один раз |
| Группы и стратификация | Разобрано ограничение StratifiedGroupKFold | Все положительные объекты одной группы оказываются только в одной из трёх проверочных частей |
| Временное разбиение | Добавлена исходная схема TimeSeriesSplit; gap=0 на ней указан явно | Восстановлены четыре набора train/test исходного примера на 100 объектах |
| Временной зазор | Добавлена полная таблица трёх шагов для 12 строк и gap=2 | Модель видит только метки, использующие исходы до начала проверки; строки 4/5 требуют будущих исходов 6/7 |
| OOF-AUC | Прежнее утверждение раскрыто на четырёх числах | AUC в каждой части равна 1, pooled AUC=3/4; сдвиг второй шкалы не меняет её порядок |
| Ограничение мощности | «Ровно 500» отделено от «не более 500» | При p=0.01 затраты положительного решения 0.99 против 0.1 для отрицательного |

Добавлены три подзаголовка внутри CV: стратификация, новые группы,
прогноз будущего. Остальной порядок главы и прежние якоря сохранены.
OOF-пример не предлагается как метод калибровки; сдвиг нужен для
демонстрации зависимости pooled-метрики от шкал разных моделей.
Медицинские числа остаются условным разбором, не клинической рекомендацией.
