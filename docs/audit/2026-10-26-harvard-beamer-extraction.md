# Harvard Beamer: формулы, таблицы, рисунки и заметки

26 октября 2026. Локальная редакция; без staging, commit, push и deploy.
Оригиналы Harvard закреплены за коммитом
`45ecc8d82fcae70c149cdce550d3b3d3411df913`.

## Проверенный дефект и исправление

Старый `clean_tex` удалял неизвестные команды, в том числе математические,
не разбирал вложенные группы и смешивал `note` с телом слайда. Имена рисунков
из `safeimg` оставались текстом. Отдельные `mlsysfocus` не попадали в
последовательность. Сайт частично восстанавливал формулы при отображении,
но повреждённый Markdown для Obsidian это не исправляло. Исходный TeX был
сохранён и до этой итерации.

`publishing/tools/harvard_beamer.py` разбирает наблюдавшийся диалект курса без
исполнения TeX. Формулы защищены от преобразования прозы; простые локальные
макросы раскрываются по определениям оригинала. Неизвестные конструкции
остаются видимыми. Заметки вынесены в отдельные свёрнутые блоки исходного TeX.
Отступы TeX больше не создают случайные Markdown code blocks. Доллары валюты,
соседние строчные формулы, типографские кавычки и акценты имеют отдельные тесты.

Восстановлены 35 архивных страниц: 1311 явных `frame`, 35 титульных вызовов и
35 `mlsysfocus`; отдельно сохранены 1311 заметок преподавателя. Строковый поиск
даёт ещё один `begin{frame}`, но это пример внутри комментария Network Fabrics,
не потерянный слайд. Нумерация блоков архива не воспроизводит добавленные темой
Beamer служебные разделители. В итоговом HTML находятся 386 таблиц. Три
объединения столбцов представлены ячейками с явной подписью исходного диапазона;
условные вероятности внутри таблиц не превращаются в дополнительные столбцы.

## Рисунки и происхождение

Загружены только используемые нативные SVG: 269 файлов, 1 663 123 байта,
270 размещений. Они перенесены без изменения байтов. Для каждого проверены
SHA-256 и Git blob SHA-1 закреплённого дерева; XML проверен на активные элементы
и внешние href. Рядом с рисунками указаны авторы курса, закреплённый оригинал
и репозиторная лицензия CC BY-NC-SA 4.0. Никаких новых схем не нарисовано.

Четырнадцать растровых файлов оставлены прямыми ссылками на исходники:
их индивидуальное происхождение не проверено. Декоративные обложки не
подсчитываются как смысловые иллюстрации и не загружались.

Метаданные: `slide-assets-tree.json`, `slide-assets-manifest.json`,
`slide-projection-audit.json` и `slide-source-review.json` в
`05 Источники/Courses/Harvard ML Systems/`. Закреплённый ответ Git tree
сохранён, поэтому повторная проверка не зависит от временного каталога.

## Два замечания к самому источнику

На слайде Edge «The Training Memory Amplifier» равные вертикальные интервалы
подписаны 100, 200, 400 и 800 MB без обозначения нелинейной шкалы. Доли памяти
по высотам составных столбцов читать нельзя. Подпись о преобладании активаций
этим графиком не подтверждается. Оригинал оставлен в архиве с видимым
предупреждением; в каноническую Edge-главу он не перенесён.

На слайде «Transformer Compute Cost» приведённая формула с его же размерами
даёт 86 973 087 744 и 356 241 767 399 424 FLOPs, отношение 4096. Это не
напечатанные в таблице 7G, 314T и 45 000×. Расчёт исполнен в регрессионном тесте,
расхождение объяснено рядом с неизменённой таблицей. Это проверка внутренней
арифметики источника, не измерение GPU и не полный расчёт стоимости моделей.

Оба замечания привязаны к хешу конкретного исходного слайда. При изменении
оригинала импортёр не переносит на него старый вывод автоматически.

## Остаток общей задачи

Восемь `mlsyscode` и один сложный `texttt` сохранены как TeX-фрагменты,
с явной пометкой, что это не исполненные примеры. Растровые ссылки остаются
без собственной проверки происхождения. Полная тематическая интеграция
Harvard, HSE и Efficient DL, семантические карты, интерактивная практика и
остальные замечания к точности и правам на материалы не закрыты. Карта переноса
не получила ложных повышений статусов.

PPO/DPO/RLVR/GRPO не редактировались; их SHA совпадают с принятыми редакциями
24–25 октября. Каноническая Edge-глава и оригиналы лабораторий тоже не
переписывались в этой итерации. Перевод, коммиты и публикация не выполнялись.
