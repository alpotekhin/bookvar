Masked diffusion — MDLM, LLaDA and block generation

Consider a four-token sequence: The cat sleeps here. An autoregressive model generates it by sampling The, then cat conditioned on The, then sleeps conditioned on both preceding tokens. A masked diffusion model can instead start with four [MASK] tokens, reveal sleeps first, then fill other positions using everything already visible on either side. The output positions exist before their contents are known.

One possible step[MASK][MASK]sleeps[MASK]

CompleteThecatsleepshere

This is a hand-constructed trajectory, not the output of a model run. Words stand for tokens only in this example. A step can reveal several positions, or none; it need not move from left to right. Once a position is committed, the basic MDLM sampler keeps it unchanged. Revising a committed mistake requires a different sampler, discussed below.

The prerequisites are self-attention, masked language modeling, and autoregressive likelihood. The exposition follows MDLM §§3–4, LLaDA §2, and Block Diffusion §§2–3. The longer Kuleshov group tutorial also connects these mechanisms to subsequent architectures and post-training. The examples below are added to work through the equations, not reported experiments from those papers.

Here δa\delta_aδa​ assigns probability one to token aaa. At t=0t=0t=0 the sequence is clean; at t=1t=1t=1 it is entirely masked. At t=0.75t=0.75t=0.75, each position is independently masked with probability 0.75. In a four-token sequence the expected number of masks is three, but a particular sample can contain zero, one, two, three or four masks.

To construct a complete forward trajectory, a masked position must remain masked as noise increases. For s<ts<ts<t, a still-visible token is removed with probability (αs−αt)/αs(\alpha_s-\alpha_t)/\alpha_s(αs​−αt​)/αs​. This is an absorbing state process. Training usually does not execute every intermediate transition: it samples ttt and creates ztz_tzt​ directly from the marginal above. The original clean sequence remains available as the target.

A bidirectional Transformer reads ztz_tzt​ and predicts a distribution over clean vocabulary tokens at each position. All predictions use the same input state; a prediction for one missing position is not already an observation for another position in that forward pass.

Some denoisers also receive the noise level ttt explicitly; it is omitted from the probability notation here. MDLM evaluates both time-conditioned and time-independent variants. LLaDA uses its bidirectional predictor without a separate time input. These choices matter when reusing a prediction at another noise level.

For example, the model might receive The [MASK] sleeps [MASK]. Both missing positions can attend to The and sleeps, including visible tokens to their right. This is the architectural connection to BERT. The model still needs positional information: two identical mask-token embeddings must be distinguishable by where they occur.

Training averages over masking rates

Заголовок раздела «Training averages over masking rates»

MDLM’s SUBS parameterization incorporates two constraints. The predicted clean token cannot itself be [MASK], so its mask-token logit is set to −∞-\infty−∞. At visible positions the clean-token distribution copies the input token. Consequently, only masked positions contribute to the loss. These are constraints on the parameterization, not abilities the network must discover from examples.

Suppose L=4L=4L=4, t=0.25t=0.25t=0.25, and a particular draw masks two positions. The probabilities assigned to their correct tokens are 0.8 and 0.5. The sampled per-token loss is

−log⁡0.8−log⁡0.54⋅0.25≈0.916291.\frac{-\log0.8-\log0.5}{4\cdot0.25} \approx0.916291.4⋅0.25−log0.8−log0.5​≈0.916291.

Dividing by the observed number of masks instead would give 0.458145. That is a different estimator. The denominator in this objective uses the sequence length and sampled masking probability, not a replacement by the actual mask count. A draw with no masks contributes zero; forcing one position to be masked changes the sampling distribution.

This code checks the reduction and weighting of supplied probabilities; it does not train a Transformer. A training implementation obtains those probabilities from logits and differentiates the corresponding weighted cross-entropy. Near t=0t=0t=0, the factor 1/t1/t1/t and rare masking events can produce high-variance estimates. Practical schedules, lower cutoffs and low-discrepancy sampling need to be specified when reproducing training. Block Diffusion §§4–5 studies this variance explicitly.

BERT also learns to predict missing tokens, but its original corruption recipe uses a fixed selected fraction and a mixture of replacements. Replacing that recipe with one masking rate does not establish the generative model above. MDLM defines a complete corruption path, reverse transitions and likelihood objective over the range of noise levels.

A complete sampler on a two-token distribution

Заголовок раздела «A complete sampler on a two-token distribution»

Consider a dataset containing only red fox and blue whale, each with probability one half. The clean-token predictor below computes the exact conditional marginal distributions from that dataset. It substitutes for a learned neural network so that sampling errors can be separated from errors in learning.

With both positions masked, each predicts two alternatives with probability one half. After red is visible, the second position predicts fox with probability one. The two positions are dependent even though each individual marginal is easy to compute.

The sampler starts from pure masks, recomputes the conditional predictions after its state changes, and samples each position from the reverse transition. It performs no model loading or training. The carry-over check holds even for an invalid final pair such as red whale: a committed mistake also remains committed.

An invalid pair can appear when both positions are revealed in one step. Independent draws from their marginals produce four equally probable pairs. Two never occur in the dataset. More steps reduce the chance of simultaneous revelation and let one sampled token condition the other.

For a linear schedule with TTT equally spaced reverse steps, each position has a uniform reveal-step index in {1,…,T}\{1,\ldots,T\}{1,…,T}. Their independent indices coincide with probability 1/T1/T1/T. When that happens, the two independent token draws disagree with probability 1/21/21/2. Otherwise the second reveal sees the first and is correct. Therefore, in this particular toy model,

P(invalid pair)=12T.P(\text{invalid pair})=\frac{1}{2T}.P(invalid pair)=2T1​.

This gives 0.5, 0.25 and 0.125 at one, two and four steps. It is an exact calculation for the specified dataset and sampler, not an error rate for LLaDA or a general scaling law. A Transformer can model dependencies through its shared input, but independent token draws in a finite reverse step do not become a joint draw merely because attention is bidirectional.

LLaDA: a bidirectional predictor trained at language-model scale

Заголовок раздела «LLaDA: a bidirectional predictor trained at language-model scale»

LLaDA uses a Transformer mask predictor and the same broad pre-training and instruction-tuning stages as an autoregressive language model. Its attention is bidirectional. Removing the causal attention mask from a decoder-style backbone changes which positions can communicate; it does not by itself train the denoising conditionals needed above.

During pre-training, random noise levels determine which input tokens become masks, and the model reconstructs their original values. During SFT, the instruction remains visible while only response positions are corrupted. The target at a masked response position is its own clean token, not the next token shifted by one. Loss normalization must use the selected response region, including any EOS positions the recipe trains. In the original LLaDA SFT recipe, short responses are padded with EOS tokens, which are trained as ordinary targets. These positions are not automatically excluded by a generic padding mask.

In the pinned LLaDA guidelines, masking probability is bounded below by a small epsilon. The guidelines illustrate the loss and data format; they are not a complete released pre-training pipeline. Their snippets also contain inconsistent variable names, so they should not be presented as a program that runs unchanged.

The reference generator divides a fixed output length into blocks and allocates a number of token commitments to each step. In low_confidence mode, candidate tokens are ranked by their predicted probabilities; the highest-confidence candidates are committed, while other proposals remain masks. random uses random scores instead. These policies differ from independent Bernoulli reveal decisions in the MDLM ancestral step.

The name remasking in this implementation does not mean that it can erase any previously committed token. The code restricts selection to currently masked positions and copies visible values. Proposing a value and then leaving that position masked differs from remasking a value already included in the persistent sequence. ReMDM makes the latter operation explicit.

LLaDA’s original paper studies an 8B model trained from scratch. Its results are evidence for that model and protocol, not proof that replacing every autoregressive objective with masked diffusion improves quality. See LLaDA §2 and Appendix B.4.

Block diffusion changes the factorization and the attention mask

Заголовок раздела «Block diffusion changes the factorization and the attention mask»

Marianne Arriola et al., Block Diffusion v3, Figure 1, CC BY 4.0. Complete original SVG. Earlier blocks are clean context; the active block is generated by diffusion before the next block begins.

The figure’s parallelism label refers to positions within a block; successive blocks still depend on earlier ones. Its quality labels summarize the paper’s comparisons, not guarantees for every checkpoint.

A fixed mask array fixes the number of output positions. Block diffusion instead factorizes a sequence into successive blocks:

pθ(x)=∏b=1Bpθ(x(b)∣x(<b)).p_\theta(x)=\prod_{b=1}^{B}p_\theta(x^{(b)}\mid x^{(<b)}).pθ​(x)=b=1∏B​pθ​(x(b)∣x(<b)).

Each conditional is a diffusion process within the current block. Blocks are generated in order, while positions inside a block can be revealed together or in arbitrary order. A block size of one recovers a tokenwise factorization; a single full-sequence block gives the opposite endpoint. Sampling efficiency and training variance still depend on the recipe.

In BD3-LMs, attention is block-causal. A token can see all positions in its own block and earlier blocks, but not later blocks. With four tokens in blocks of size two, the permitted attention rows are

The completed first block cannot see the changing second block. With fixed positions and noise conditioning for that clean context, its hidden states, keys and values remain valid while the second block is denoised. The active block’s own representations change when its masks are filled and normally require recomputation.

Merely generating blocks with a fully bidirectional Transformer does not establish this invariance. At deeper layers, even an unchanged prompt token has attended to changing answer positions. For example, with uniform attention and scalar values 2 for a prefix token and 0 for an active token, their mean is 1. Replacing the active value by 6 changes the mean to 4. A subsequent projection of the prefix state changes too. An exact prefix KV cache requires the appropriate attention structure, not just the word “block” in a sampling option.

Training must also prevent target leakage. To denoise block bbb, the model needs its noisy version and clean earlier blocks. To use block bbb as context for a later block, it needs the clean version of bbb. The source’s vectorized training concatenates noisy and clean streams and uses a specialized attention mask so that a noisy target cannot read its own clean copy or a later clean block. This is described in Block Diffusion §3.2 and Appendix B.6. Changing only the attention mask of one clean stream would expose answers.

ReMDM permits a committed token to become uncertain again

Заголовок раздела «ReMDM permits a committed token to become uncertain again»

ReMDM adds a probability σt\sigma_tσt​ of remasking a visible position. It also changes the transition out of the masked state so that the desired marginal visible fraction remains αs\alpha_sαs​. Under the known-clean-data posterior in ReMDM §3.1, a visible token survives with probability 1−σt1-\sigma_t1−σt​, while a masked position is revealed with probability

For αt=0.5\alpha_t=0.5αt​=0.5, αs=0.75\alpha_s=0.75αs​=0.75, and σt=0.25\sigma_t=0.25σt​=0.25, one quarter of the visible positions are removed. Masked positions are filled with probability 0.75. The probabilities are valid only when 0≤σt≤min⁡(1,(1−αs)/αt)0\le\sigma_t\le\min(1,(1-\alpha_s)/\alpha_t)0≤σt​≤min(1,(1−αs​)/αt​) for αt>0\alpha_t>0αt​>0. At αt=0\alpha_t=0αt​=0, there are no visible positions to remove. Previously visible tokens must not be remasked at the final clean endpoint.

These are posterior schedule calculations, not a complete ReMDM sampler. During generation the network supplies the clean-token probabilities. A remasked mistake can be replaced using the surrounding context at a later step, but correct tokens can also be removed. Neither more steps nor a large σt\sigma_tσt​ guarantees improvement for every sample.

In ReMDM-loop, ordinary unmasking first creates a partial candidate. During an intermediate phase, αs=αt\alpha_s=\alpha_tαs​=αt​ is held constant and remasking is enabled. At α=0.5\alpha=0.5α=0.5, σ=0.25\sigma=0.25σ=0.25 gives a masked-to-visible probability of 0.25: the expected removed and restored masses balance. The final phase disables remasking and fills the remaining positions. This separates spending computation on refinement from progressing toward a fully visible sequence. The paper also studies capped, rescaled and confidence-dependent remasking schedules; they are distinct choices, not consequences of the name “diffusion”.

Likelihood, latency and what to compare

Заголовок раздела «Likelihood, latency and what to compare»

An autoregressive model assigns an exact tractable likelihood by summing token log-probabilities along the observed prefix. A masked diffusion model defines probability through latent trajectories; its common evaluation uses a variational bound estimated over noise levels and corruptions. Exponentiating a per-token NELBO produces an upper bound on perplexity, subject to estimation error. It must not be relabeled as exact autoregressive perplexity. Loss from one arbitrary mask pattern is not the sequence likelihood either.

Predicting a whole block per pass does not automatically make generation faster. An autoregressive decode step processes a new token using cached prefix state; a fully bidirectional denoising step can process the whole sequence again. Report the number of network evaluations, tokens processed per evaluation, block size, cache policy and actual end-to-end latency. Count extra unconditional evaluations if classifier-free guidance is used.

MDLM §4.1 describes another form of reuse: when a step reveals no tokens, the next input sequence is identical. A time-independent denoiser can reuse its entire clean-token prediction and apply a new reverse-transition probability without another network call. This is not a prefix KV cache. It becomes invalid when an input token changes, or when a changed time embedding changes the denoiser’s input.

For an output of LLL tokens split into BBB blocks, with KKK denoising passes per block, the nominal denoiser count is BKBKBK, not merely KKK. Cache-building passes and stopping checks may add work. This count is still not FLOPs or elapsed time: a full block pass can reuse weights across many positions and use the GPU differently from tokenwise decode. See prefill and decode and performance measurement for the corresponding hardware model.

For instruction-following, compare generated answers, not only masked reconstruction. Keep tokenizer, prompts, length budget, sampling policy and benchmark protocol explicit. A preserved prompt is conditioning, not evidence that every instruction will be obeyed; a corrected grammar example does not establish general reasoning or reliable tool use.
