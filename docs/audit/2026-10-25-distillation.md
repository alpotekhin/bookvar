## Исполняемые примеры

`publishing/tools/check_distillation_examples.py` выполняет семь Python-блоков
самой главы в исходном порядке, затем независимые проверки. Финальный запуск
напечатал приведённый выше SHA канонического файла.

```sh
uv run --offline --with torch==2.14.1 --with transformers==4.57.1 \
  --with numpy==2.3.5 python publishing/tools/check_distillation_examples.py
```

Проверены CE целых ответов и градиенты, смесь мягких и жёстких целей,
причинный сдвиг, разные длины ответов, включение EOS и исключение PAD.
Восемь сочетаний температуры и редукции сопоставлены с независимой формулой
KL и аналитическим градиентом; выполнен float64 gradcheck. Замаскированные
NaN, ±inf и большие значения исключаются до вычисления потери и не влияют
на градиент. Недопустимые формы, типы, метки, температуры и пустые маски
проверены отдельно. Общий сдвиг логитов и высокотемпературный предел проверены.

Из сохранённого неизменённого `gkd_trainer.py` извлечена и исполнена только
статическая `generalized_jsd_loss`. Пять β сопоставлены с независимыми
формулами и градиентами; неравные микропакеты сохраняют общий знаменатель.
Это не импорт и не запуск полного GKDTrainer.

В видимом примере действительно выполнен шаг маленького Llama на CPU:
учитель с двумя слоями, ученик с одним, hidden size 16, словарь из 16 ID,
случайные веса, seed 29. Ученик генерирует по три токена к двум запросам;
обе модели получают одинаковые префиксы. Маска начинается с позиции,
предсказывающей первый токен ответа. Учитель не получает градиентов и
сохраняет параметры. На тех же генерациях KL меняется
`0.00644196 → 0.00554519`. Фиксированная длина без EOS/PAD в этом отдельном
примере указана явно. В тексте объяснено, что на следующей итерации нужно
получить новые генерации; запуск нескольких итераций здесь не заявляется.
