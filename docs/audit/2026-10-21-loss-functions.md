## Исполненные примеры

`publishing/tools/check_loss_functions_examples.py` — PASS, CPU/NumPy.
Оба опубликованных блока исполнены последовательно.
Проверены непосредственно и конечными разностями:

- softmax для (3.2,5.1,−1.7), NLL 2.04035515280017;
- p−q, мягкая цель, ненормированная цель с градиентом S·p−q;
- шаг η=.1, прежний argmax и новая потеря 1.8909237270947268;
- внешнее произведение с признаками (2,−1);
- неправильная повторная нормировка вероятностей: 1.3795068861455881;
- сдвиг на 1000, конечный log-softmax при (1000,0);
- H(q)=.673011667, KL=.104649629, CE=.777661296 и асимметрия KL;
- токенное и документное усреднение .6/.75; прямые градиенты маски 1/3 или 0;
- MSE 11/3, MAE 5/3, производная MSE; плотность и NLL для трёх дисперсий;
- точное разложение ожидаемого Brier и риски .24/.28;
- BCE/Brier при p=.01, устойчивый BCE при логитах ±1000;
- L2-штраф .05 и градиент (.04,−.02).

Не заявляются обучение модели, запуск PyTorch autograd или полного
TinyTorch suite. Правила API сверены с документацией PyTorch 2.14,
а не выданы за испытание установленного пакета.
