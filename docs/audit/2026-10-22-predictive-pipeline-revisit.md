| Механизм | Изменение и проверяемая цепочка |
| --- | --- |
| Доступность метки | Для прогноза 1 июля уход 10 июля уже определяет положительный ответ. Отсутствие ухода 15 июля не даёт отрицательного; нужны весь горизонт и доступная история. Объяснён перекос отбора свежих наблюдений только по уже известным ответам. |
| fit/predict/score | К двум исходным схемам добавлена оригинальная схема score. Ответы поступают в вычисление метрики, не в подбор коэффициентов. Accuracy класса LogisticRegression отделена от прикладного выбора метрики. |
| Реальный прогноз конвейера | Прежний отдельный пример с вручную заданными весами заменён продолжением опубликованного fit. Четыре столбца преобразования сопоставлены с четырьмя обученными коэффициентами, затем с логитом, сигмоидой и порогом. |
| Регуляризация | Для разделимой игрушечной таблицы объяснено, почему при L2 и C=1 веса конечны. Увеличение ненулевых весов уменьшает data loss, но увеличивает штраф. |
| Неизвестная категория | Нулевая one-hot группа не означает нулевой риск. На второй новой строке все признаки нулевые, поэтому остаётся смещение и вероятность около 0.5. |
| Обучение преобразований | Схема Pipeline.fit относится к преобразованию без использования y. Для SelectKBest добавлена оговорка: Pipeline.fit передаёт обучающие ответы также промежуточному преобразователю. |
