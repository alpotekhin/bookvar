## Проверка объяснений

| Механизм | Конкретный разбор |
|---|---|
| Projector | Три вектора ширины 2 проецируются в ширину 3; показаны все выходные координаты. MLP сохраняет число позиций; рассчитаны параметры двух указанных вариантов |
| Вставка изображения | Маркер заменяется тремя embeddings. Итоговые девять позиций, IGNORE_INDEX и predictor positions 6/7 связаны со сдвигом targets |
| Prefill/decode | 576 + 40 = 616; prefill уже даёт первый ответ, после ввода выбранного токена cache содержит 617. Teacher forcing длины 676 разобран отдельно |
| KV memory | Для явно заданного 32-layer MHA decoder: 576/64/32 visual positions требуют 288/32/16 MiB; это не измерение BLIP-2/Flamingo |
| Q-Former ITC | Два queries, два сходства 1 и 0, максимум 1. Показан запрет обмена с текстом до contrastive сравнения |
| Q-Former ITM | Два вектора logits дают среднее (-0.5, 1.5) и вероятность 0.880797; среднее отдельных вероятностей примерно 0.841816 — другое вычисление |
| Q-Former ITG | Полная маска для двух queries и трёх текстовых позиций, пример подписи и запрет будущего target |
| BLIP-2 stage two | 32×768 → 32×4096; отдельно visual prefix OPT и вход encoder FlanT5 с текстовым prefix/suffix |
| Flamingo | Два нулевых gates, градиент gate -2 при нулевом градиенте ветви; маска пяти текстовых позиций и двух изображений |
| Resampler | Два queries читают четыре признака и два latents. Матрица 2×6 вместо 2×4; показаны веса и итоговый первый вектор (1.6519, 0.4696) |
| DeepStack | Три дополнительных уровня добавляются только к двум visual positions; длина пяти позиций не меняется. Указано, что между реальными внесениями стоят decoder blocks |
| Замороженная LLM | Нативный PyTorch пример: loss 20, frozen weight.grad отсутствует, projector получает [[4,8],[18,36]]. no_grad обрывает нужную связь |

Требующие отдельной главы данные, высокое разрешение, OCR и
программа обучения не подменены краткими определениями здесь:
к ним сохранены переходы в 64b/64c и далее. Выводы VILA
ограничены её абляцией; frozen LLM не объявлена заведомо непригодной.
