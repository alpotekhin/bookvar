| Механизм | Объяснение и пример |
|---|---|
| Разделение и объединение осей | `(head coord)` задаёт подряд идущие признаки головы. Для 0–23 проверены reshape/transpose и обратный merge; отдельно показано отличие `(coord head)` при совпадающей форме. |
| Произведение по именованным осям | Общая `coord` суммируется, `batch/head` сохраняются, разные `query/key` образуют пары. Запрос `(0,1)` и обращённые ключевые строки дают оценки `(9,5,1)`. Это не объявлено softmax-весами. |
| Свёртка одного входа | Сумма квадратов по `coord` оставляет результат для каждой строки. Ряды `(0,1)`, `(4,5)`, `(8,9)` дают `(1,41,145)`; операция отделена от нормировки attention. |
| Ограничения записи | Имена не хранятся в самом тензоре; перестановка одинаковых осей может пройти. Объяснены роль `...`, порядок координат и отсутствие обещания ускорения/нулевого копирования. |

```sh

  --with numpy==2.3.5 python publishing/tools/check_masking_heads_examples.py
```
