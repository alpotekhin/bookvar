## Проверка объяснения

- Память: 10 млн FP32-параметров → 40 MB; четыре массива → 160 MB.
  Голова 128→10 со смещением → 1290 параметров → 20 640 байт четырёх массивов.
  Тысяча 128-мерных FP32-признаков → 512 000 байт. Замороженная основа
  и рабочие буферы не исключены из бюджета.
- Обратный проход: a=(2,-1), W=((1,3),(2,4)), b=(.5,-.5), g=(.1,-.2).
  z=(.5,1.5), da=(-.5,-.6), dW=((.2,-.4),(-.1,.2)), db=g.
  Вход нужен для градиента W, но не для db. Битовая маска ReLU и фактическое
  хранение в runtime разделены.
- FedAvg: веса 100/300 дают (4,6); равные веса дают (3,5);
  после допустимого выпадения второго клиента результат (1,3).
  При пороге безопасной агрегации раунд может отменяться.
- Локальные шаги: для двух квадратичных целей один шаг даёт 2.55,
  два локальных шага и среднее дают 2.865, два центральных — 2.92125.
  Среднее локальных минимумов 3 отличается от общего минимума 48/13.
  Локальные эпохи не смешаны с числом mini-batch шагов.
- Сеть: 100 клиентов × две передачи 40 MB × 100 раундов → 800 GB.
  Только 100 тысяч параметров адаптера в обе стороны → 8 GB; загрузка
  основы, повторы и накладные расходы вынесены из этой оценки.
- Маски: [5,7,-2] → [9,12,86] modulo 97; сумма 10.
  Без третьего сообщения маски не сокращаются: 21 вместо 12.
  Это арифметический пример, не криптографическая реализация.
- DP: (3,4), C=2 → (1.2,1.6); соседство add/remove против replacement;
  при фиксированном m среднее имеет replacement-границу 2C/m.
  Десять (.2,1e-6) → (2,1e-5) по базовой композиции.
- Метрики: [9/10,50/100] дают .7 по пользователям и 59/110 по объектам.
  Оба результата ограничены составом наблюдавшихся клиентов.

Оставшиеся ограничения каждого примера указаны рядом с объяснением.
Проверка чисел не заменяет проверку механизма и не является измерением
качества модели, энергопотребления или безопасности.
