## Источники и приёмка объяснения

Использована та же закреплённая JMLR-статья Raffel et al.:
`05 Источники/Originals/positional-information-2026-10-21/t5-jmlr.pdf`,
SHA-256 `66cf9f77e46691853703eb6982dea337a53361d509fb99be719b5410c5467e41`.
Повторно прочитаны относящиеся к изложению §2 и §3.1–3.7,
включая Tables 2–15; Figure 6 осмотрена на полной странице 29
и в итоговом crop. Даты публикаций сверены с JMLR и историей arXiv;
описание T5.1.1 — с закреплённым `released_checkpoints.md`.

В Transformers 4.57.6 прочитаны нормализация, attention с относительными
корзинами и cache-веткой, `_shift_right` и используемый forward условной
генерации. Исполняемый `modeling_t5.py` проверен побайтно относительно
архива на ревизии `753d61104116eefc8ffc977327b441ee0c8d599f`.
Сравнение с официальным T5 preprocessing продолжает проверку, описанную
в предыдущем отчёте; новое воспроизведение всего TensorFlow pipeline
не заявляется.

| Механизм / ошибка | Проверенное объяснение и результат |
| --- | --- |
| Вторая пара учебного batch | Из `[3,9,4]` получается source `[3,14,4,1]`, target `[14,9,13,1]`. Исправлен пропущенный closing sentinel 13 вместо 12; показано происхождение пары. |
| Регрессия проверяющего кода | Прежний перебор обратимых масок не проверял согласованность опубликованных пар самого batch. Теперь обе пары независимо выводятся через `replace_runs`, проверяются порядок sentinels и обратное восстановление. |
| Self/cross-KV | На двух decoder-слоях и семи позициях self K/V вычисляются семь раз, cross K/V — один раз на слой. Формы и рост cache проверены на каждом шаге, logits сопоставлены полному forward. |
| Изменение source | `[2,3,4,1]` → `[2,3,9,1]` меняет готовые encoder-состояния даже общего префикса. Объяснено отличие от causal GPT. |
| Отрицательный cache-контроль | Новая encoder memory со старым cache даёт в точности старые logits. Полностью новый cache даёт другие logits. Self-KV второго decoder-слоя тоже различаются: обновления одних cross-KV недостаточно. |
| Повторение корпуса | Figure 6 показывает training loss, Table 9 — отдельное downstream-качество. 4096 повторов, SuperGLUE 71.36 → 59.29, оговорка о небольшом эффекте 64 повторов. |
| Старая Papers-заметка | Исправлены дата, версия arXiv, C4 thresholds, отсутствие encoder-only в Table 2, ограничения сопоставимости, исходный/final рецепт и метрики. Table 15 не названа независимой оценкой вклада каждой настройки. |
| Старый concept | Выдуманные таблицы заменены строками с условиями из Tables 2, 4–8, 12–14; исправлены SQuAD 1.1 EM/F1, WMT, SuperGLUE, длина target, кэш causal decoder и разграничение 3B/11B и T5.1.1 XL/XXL. |

Пример выполняется на случайно инициализированной маленькой CPU-модели,
не на выпущенных весах. После исправления пары loss одного шага SGD
равен `3.22853946685791 → 2.9341156482696533`.
Независимый функциональный forward/backward совпадает с библиотечным;
максимальная абсолютная ошибка градиента `1.862645149230957e-09`.
В отрицательном контроле максимальные изменения: encoder prefix
`1.6601642370224`, stale/fresh logits `0.5606187582015991`, self-KV
второго слоя `0.5189022421836853`. Это проверки зависимости состояний,
не измерения качества или скорости T5.
