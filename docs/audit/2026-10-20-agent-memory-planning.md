## Содержательная проверка механизмов

| Механизм | Пройденный случай и исправление |
|---|---|
| Память MemGPT | Поиск письма → первая страница → следующая → чтение → ответ; heartbeat отдельно от размера окна и обновления весов |
| Обобщение памяти | 100 последних записей → три вопроса → извлечение → вывод со ссылками; порог 150 привязан к опыту авторов |
| История и действующее значение | Новая дата supersedes старую; subject требует реальной фильтрации и не объявлен защитой сам по себе |
| Ранжирование | Сырые часы/важность/близость → min-max каждого столбца → суммы 2.712486, 1, 1.875; исходное округление 2.713 исправлено |
| PPR | Два начальных узла → [0.075,0.075,0.85] → [0.43625,0.43625,0.1275] → [10/37,10/37,17/37] |
| Формальный план | send до book отклоняется, book → send выполняет предусловия; domain предоставляется экспертом, а не генерируется моделью |
| ToT | Из [6,9,13] ветвь [7,9] не даёт 24, [4,6] даёт; объяснены отбор, отсечение, ограничение ширины и отличие self-consistency |
| UCT / LATS | При N(parent)=10 второй, реже посещённый узел получает 1.573 против 1.236; реальные наблюдения отделены от world-model predictions |
| WebDreamer | Три двухшаговые воображаемые траектории → один реальный клик; 0.8/0.4/0.1 не объявлены вероятностями |
| Reflexion | Ошибка на )( → контрпример → правило префикса → другая заранее написанная программа; лимит и первый успех останавливают цикл |
| Качество оценщика | Без контрпримера плохая программа проходит данные тесты; статус не объявлен доказательством корректности |
| Оркестрация | Смена числа участников инвалидирует помещение, но не обзор с неизменной темой; проверка зависит от полноты контракта |
| Конкурентность | Проверка и запись должны быть атомарны; обычный словарь не выдан за транзакцию |
| Параллельность | Условные 70+100+10=180 и max(70,100)+10=110; это расчёт зависимостей, не замер ускорения |

На оригинальном Figure 2 Reflexion условие while использует or. Оно оставлено
