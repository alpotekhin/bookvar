## Проверка примеров

`publishing/tools/check_t5_examples.py` исполняет оба Python-блока главы.
Окружение: CPU, PyTorch 2.14.1, Transformers 4.57.6,
SentencePiece 0.2.1. Веса выпущенной T5 не загружаются.

Проверены:

- Реальный tokenizer из `cc_all.32000/sentencepiece.model`, legacy=True;
  все приведённые ID и порядок 100 extra IDs. SHA модели:
  `d60acb128cf7b7f2536e8f38a5b18a05535c9e14c7a355904270e15b0945ea86`.
- Восстановление исходных ID по source/target и исчерпывающий перебор
  малых масок, начинающихся чистым токеном, при длинах 2–8.
- Номера relative buckets для 2001 смещения в обоих режимах:
  независимый расчёт Python сопоставлен с Transformers.
- Отдельный функциональный forward двух стеков по тем же весам:
  embeddings, нормы, self/cross attention, общий relative bias,
  FFN, финальные нормы, rescale и связанный выход.
- Совпадение выходов и всех градиентов: максимальная абсолютная ошибка
  `3.725290298461914e-09`.
- Причинная видимость, padding source и последовательное накопление
  self/cross-KV в сравнении с полным проходом.
- Число параметров Base на meta-устройстве, длины, память, NLL,
  смесь, adapters, LR и токенные бюджеты.

Один SGD-шаг учебной сети уменьшает loss с 3.2278738021850586
до 2.9041357040405273. Это проверка вычислений на искусственном пакете,
не воспроизведение benchmark-качества или производительности T5.
