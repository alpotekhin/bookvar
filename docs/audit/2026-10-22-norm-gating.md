## Приёмка механизмов

| Механизм | Содержательная проверка |
| --- | --- |
| Residual | Полный пример `(1,2,3) → (1.1,1.8,3)`, якобиан и входящий градиент. Контроль `F=-I` не позволяет выдать прямой путь за гарантию ненулевых производных. |
| Pre-/post-norm | Одни входы и `F(z)=0.1z`, разные выходы и полные якобианы; показаны обе производные для цели первой координаты. Сравнение одного подслоя не выдано за всю LM. |
| Warm-up | Условия mean-field анализа отделены от эмпирических gradient profiles и обучения переводчика/BERT. Нулевые Q/K — условие упрощённого анализа, не устройство обученной модели. |
| LN/RMS | Вычислены обе нормировки `(3,4,0,0)`, среднее, дисперсия, связь `E[x²]=Var(x)+mean(x)²`, квалификации для epsilon, gain и bias. |
| RMS backward | Аналитическая VJP и пример `(0.256,-0.192,0,0)`; detach знаменателя сохраняет forward, но даёт неверные `(0.4,0,0,0)`. |
| Epsilon/dtype | 0.03162 против 1.66667; FP16-квадрат возвращает конечные неверные нули. Статистики FP32 и порядок округления объяснены до API. |
| pRMS | Первые k координат оценивают знаменатель для всех d; конкретный случай k=1, нулевой выбранный участок, 6.25% и ограничения исходной работы. Не приписан LLaMA. |
| Результаты RMSNorm | Строки Table 4, SacreBLEU и секунды/1000 шагов с TensorFlow/V100, 300k steps. 6.9% — сокращение времени в этом опыте, не универсальный выигрыш LLM. |
| SwiGLU | Две заданные матрицы, SiLU, произведение и выход; формы, matched weight budget, Table 1 log-perplexity 1.677/1.683/1.633/1.636 и контекст опыта. |
| QK-norm | Отдельный RMS-пример одной головы, scores 7071.07 → sqrt(2), вероятности 0.8044/0.1956; граница для единичных gain не названа безусловной. Chameleon использует LayerNorm Q/K. |
| Z-loss | Общий сдвиг не меняет CE, но меняет log Z и квадратный штраф. Производная выведена и сверена; logsumexp не подменяет обучение регуляризатором. |
| Soft-capping | Изменяет распределение; наложение после маски открывает будущему ключу вероятность 0.123032. Правильная последовательность сохраняет точный ноль. |
| Norm-reordering | `X+N(F(X))` отделено от `N(X+F(X))` и `X+F(N(X))`. Рецепты 7B/34B, dropout, QK-norm, z-loss и 4000 warm-up steps не сведены к одному вмешательству. |

При повторной сверке Figure 5 обнаружено, что показанный отрезок без
QK-norm содержит колебания, но не полный разгон потерь. Последующая
расходимость теперь приписана сообщению §2.3, а не самому графику.
Figure 6c — сравнение с dropout, не окончательный 34B без dropout;
разница 7B/34B на левой панели не названа абляцией одной нормы.
