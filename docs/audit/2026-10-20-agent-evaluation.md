## Приёмка объяснений

| Механизм | Пройденный пример и ограничение |
|---|---|
| Проверка результата и политики | Одна бронь проходит; дубликат и неверное время не проходят; правильная бронь без разрешения получает outcome=true, policy=false |
| Границы тестового календаря | Проверка не контролирует письма, чужие события, полноту журнала и подлинность согласия; пустой журнал не объявлен достаточным доказательством |
| Outcome/trajectory/process | Конечная база, журнал разрешений и подготовка среды проверяются раздельно; критерий не требует единственной эталонной последовательности |
| AgentBench | Различаются успешное действие в ОС, победа в игре и F1 по сущностям; необходимость явной агрегации и отдельных оценок по средам |
| SWE-bench | Принятый PR → тестовая часть → fail-to-pass → новый патч → обе группы тестов; отсутствие теста не считается успехом |
| Ограничение SWE-bench | Исправление пустого пароля может сломать обычный вход; прохождение заданных тестов не доказывает отсутствие всех регрессий |
| τ-bench | Скрытые предпочтения → запросы к API → возврат 54.04 вместо обмена с экономией 41.64; проверяются база и строки ответа |
| Ограничение τ-bench | В исходном §3 прямо допускается r=1 при возврате без подтверждения; прежняя чрезмерная трактовка policy adherence исправлена |
| pass@k | n=10,c=2,k=3 → 56 неуспешных троек из 120 → 8/15; подстановка c/n даёт 0.488; объяснена несмещённость по индексам iid-выборки |
| Адаптивные попытки | Повтор с обратной связью не объявлен новым iid-кандидатом; цена включает все попытки |
| pass^k | C(c,k)/C(n,k), граничный случай c<k; нулевая оценка не объявлена доказательством нулевого будущего успеха |
| Неоднородность задач | Половина всегда успешна, половина никогда → все три средних 0.5, а не 0.875/0.125 от общего p |
| Выбор результата | 8/10 запросов содержат принятый кандидат, но выбран правильно лишь для 5/10; два показателя не смешиваются |
| Парное сравнение | A=[1,1,0,0], B=[1,0,1,1], разности [0,-1,1,1]; два исправления и одна регрессия |
| Bootstrap | Полный перебор 256 выборок даёт интервал [-0.5,1]; четыре задачи не выданы за достаточный размер, группы требуют кластерного анализа |
| Модель-судья | Двойное предъявление с перестановкой позиций; согласованность не отождествляется с правильностью |
| PaperBench | Новая среда и reproduce.sh отделяют код от выполнения; веса исходного дерева дают 0.75 → 0.25 → 0.5/0.4 → 0.55 |
| Калибровка судьи | Учебная матрица из 50 случаев: accuracy=.84, precision=.75, recall=.9; не объявлено результатом PaperBench |
| Редкие нарушения | Ноль из 100 даёт верхнюю одностороннюю границу 2.95%; минимум 299 для границы ≤1% при iid-предпосылках |
| Ошибки среды | 70 успехов из 98 подготовленных / 100 запланированных → 71.43% и 70%; знаменатели и неизвестный исход записи сохраняются |
| Разбор ошибки | Потеря подтверждения → повтор → дубликат; причина отделена от последствия и привязана к шагу журнала |
