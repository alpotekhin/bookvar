## Проверка объяснения

| Механизм | Конкретный разбор |
|---|---|
| Alignment | Подпись условна по изображению и вопросу; teacher forcing и завершение ответа |
| Градиент через frozen LLM | Два logits, CE 0.6931, градиент (-0.5,0.5), SGD 0.2, новая CE 0.5981 |
| Заморозка | Отделены неизменные веса от необходимости backward по входу и хранения активаций |
| Loss mask | Девять позиций; logits 4–7 предсказывают targets 5–8, ignored labels не удаляют изображение из attention |
| Packing | Блоки 5/4, запрет обмена между примерами, независимые позиции и границы |
| Два бюджета packing | 700/3 +1000/6 не проходят по tiles; 700/3 +600/4 проходят |
| Общий visual prefix | Три позиции изображения и две аннотации по две позиции; 24 разрешённые связи |
| Происхождение разметки | PixMo голос→транскрипт→caption, человек+OCR для QA, точки, код документов, synthetic clocks |
| Текстовый учитель | LLaVA captions/boxes не доказывают неизвестный номер автомобиля; учитель-VLM имеет другой вход |
| Sampling | 10M/1M/0.1M: 90.1/9.0/0.9% против 70.6/22.3/7.1%; доли примеров отделены от токенов |
| Нормировка | Target-длины 4/16 и средние ошибки 2/1: token=1.2, sample=1.5, square=4/3 |
| Curriculum | Конкретные стадии LLaVA/OneVision, InternVL, Qwen-VL и Qwen3-VL, без универсализации заморозки |
| Перенос | Исходный S1 пересчитан, S2 не выдан за журнал действий агента |
| Grounding reward | IoU 1, 1/3, 0 и явно учебный порог 0.5 |
| Distillation | Teacher (0.8,0.2), student (0.6,0.4), KL≈0.091516; направление KL не приписано закрытой реализации |

Фактические уточнения:

- В InternVL 2.5 final instruction tuning используется unified LR,
  а не обязательно отдельные rates для всех модулей.
- В Molmo connector-only стадия пропущена; все модули обучаются
  с разными rates и warmup.
- Точная square-root формула подтверждена для InternVL.
  По названию Qwen3-VL не восстановлены неизвестные mask/reduction.
- В Qwen3-VL v1 reasoning RL назван SAPO; не подставлен GRPO.
  Strong-to-weak distillation в отчёте использует text-only data.
- В Qwen3-VL первые два этапа имеют одну и ту же длину 8192.
- В Qwen-VL 1.4B корпус и 1.536B предъявлений различены.
- У OneVision указанные сводные 560K+350K+800K дают 1.71M;
  название 1.6M не выдано за точный manifest.
- LLaVA data-generation иллюстрация относится к Table 1,
  а не к ошибочно указанной прежде Figure 2.

## Ошибка в исходном качественном примере

S1 course image сохранён побайтно. На нём r=11, угол=40°,
цена Allstate=63. Площадь равна примерно 42.24.
С полной точностью стоимость 2660.93; при округлении площади
перед умножением 2661.12. Ответ модели 38.01/2386.03 ошибочен.
Даже 38.01×63=2394.63, не 2386.03.

Рядом с исходным рисунком добавлены явная оговорка,
формула и выполняемый расчёт. Ошибка не заретуширована в картинке
и не принята за ground truth. Качественная демонстрация
не названа абляционным доказательством переноса.
