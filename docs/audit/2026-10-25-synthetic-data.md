## Исполнение

Прежние диагностические файлы из временной папки сентября недоступны.
Вместо ссылки только на прошлый результат добавлен постоянный скрипт:
publishing/tools/check_synthetic_data_examples.py.

Запуск:

~~~bash
uv run --offline --with text-unidecode==1.3 python publishing/tools/check_synthetic_data_examples.py
~~~

При первом запуске зависимость text-unidecode 1.3 была получена из реестра;
повторные проверки выполняются без сети. Архив исходников, лицензии MIT
и одной полной записи SWE-Smith занимает 64 KB:
«05 Источники/Originals/synthetic-data-2026-10-25».
Веса, большие наборы данных и контейнеры не скачивались.

Скрипт проверяет хеши исходников, применяет настоящий unified diff из записи
SWE-Smith с точным сопоставлением контекста и компилирует четыре версии
в памяти. Сохранённые исходники не меняются.

| Версия | Штатные CLI-тесты | Дополнительный A->B->C |
|---|---:|---|
| Исходная | 11/11 | Два элемента, второй содержит B->C |
| С мутацией | 9/11 | Ошибка разделителя |
| Исправлен только разделитель | 11/11 | Три элемента; вызов slugify отклоняет их |
| Исправлены оба изменения | 11/11 | Правильная пара |

В ошибочной версии падают именно test_replacements_right и
test_replacements_wrong, перечисленные в FAIL_TO_PASS записи.
Исполнены оба блока главы: Python и команда Bash. Команда печатает b-cat;
исходная команда из сгенерированного условия без -- завершается с кодом 2.
Отдельно проверена арифметика смещения отбора, долей документов/токенов,
повторений, ограничения бюджета, расписания 15/9/6, исчезновения редкой
категории и стоимости принятой записи.

Это не запуск всех 81 теста метаданных, Docker-окружения или агента.
Не измерялись качество модели, скорость обучения и эффективность генерации.
Наблюдавшийся Hub revision указан в NOTICE, но не выдаётся за
криптографическую привязку ответа dataset filter API к Parquet.
