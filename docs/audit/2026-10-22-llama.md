## Приёмка объяснения

| Механизм | Источник | Проверенный ход объяснения |
| --- | --- | --- |
| Полная LM | CS336 §3.1, §3.5; первый model.py | ID → lookup → отдельные блоки → финальная норма → несвязанный выход. Пример BOS/A/B и сдвиг A/B/EOS связывает видимость с обучающей целью. |
| Pre-norm | CS336 §3.4; LLaMA §2.2 | Два сложения и отдельные нормы, случай F=0, пример пропорциональных векторов и якобианы. Положение нормы отделено от выбора LayerNorm/RMSNorm. |
| RMSNorm | RMSNorm §3–4.2; исходный класс | Полная арифметика (1,2,2), gain/epsilon, положительное и отрицательное масштабирование, сдвиг, порядок FP32/cast/gain и разные defaults класса/ModelArgs. |
| RoPE | RoFormer §3; код LLaMA | Ненулевой causal-пример query m=3/key n=1, вывод относительного произведения, несколько частот, комплексные соседние пары, отсутствие вращения V и абсолютные позиции при cache. |
| SwiGLU | Shazeer §2–3; исходный FeedForward | Обе входные ветви, SiLU, произведение и выходная матрица с промежуточными числами. Значение вентиля не выдано за вероятность. |
| Ширина и веса | FeedForward; Table 2 | 8d/3 → floor → кратность 256, точные 11008 и 0.78%, порядок w1/w3/w2, отсутствие bias и untied E/U. |
| Полный малый блок | Операции закреплённого кода, учебные веса заданы отдельно | Две позиции, causal attention/RoPE, residual/RMS/SwiGLU, финальная норма, три logits, NLL и реальное обновление всех 46 параметров. |
| Формы и ресурсы | Table 2; исходные классы | B=2/T=3 различают оси; все четыре размера FFN; точный параметрический счёт 6738415616, веса FP16 12.55 GiB и KV 1 GiB без подмены полной памяти процесса. |
| Inference-код | Первый и Llama 3 model.py | CUDA-cache конструктора, inference_mode, выход только последней позиции, позиции K/Q и ограничение старой квадратной маски; более поздняя прямоугольная маска. |
| Данные и рецепт | LLaMA §2.1–2.4; Llama 2 tokenizer | BPE/цифры/byte fallback, семь долей, обработка каждого корпуса, 45/63B токенов Wikipedia и область применимости 2.45 эпох. AdamW и training-system решения отделены от архитектуры. |
| Переходы версий | Llama 2 Table 1; апрельские Llama 3 code/card; Herd §3.4.2 | MHA первой серии, невыпущенная 34B и GQA 70B, GQA обеих апрельских Llama 3, пример 32/8, словарь, theta и отдельное продолжение до 128K. |
| Условия результатов | LLaMA §3.1–3.2, §4; первая model card | HellaSwag/PIQA без приписывания качества одному компоненту; likelihood-нормировка, фоновый Answer:, MMLU base/LLaMA-I и отсутствие chat/RLHF у базового выпуска. |

## Исполнение примеров

`publishing/tools/check_llama_examples.py` исполняет оба блока главы на CPU.
Использован `/tmp/bookvar-imbalance-venv/bin/python`.
Лог: `/tmp/bookvar-llama-examples-final.log`.

Независимо проверены:

- Все состояния forward, probabilities и NLL по скалярному/NumPy расчёту.
- Центральные конечные разности всех 46 параметров;
  максимальная абсолютная ошибка градиента 3.3073313282939304e-10.
- Loss 2.4054769191515373 → 2.3664810981834323 после SGD 0.01.
- Реальные тела исходных RMSNorm/RoPE из AST на CPU, четыре dtype,
  переполнение FP16, epsilon/gain и общие сдвиги позиций.
- Исходное тело FeedForward с тремя проекциями и отдельный числовой вентиль.
- Независимость раннего выхода от будущего токена и совпадение полного
  прохода с однотокенным KV-cache при глобальных позициях RoPE.
- Размеры ранней квадратной и поздней прямоугольной масок.
- Ширины четырёх FFN, точное число параметров 7B на meta,
  память весов/KV, доли данных и арифметика обучающего бюджета.

Проверяющие тела исходников не означают исполнение всей CUDA-модели.
Checkpoint и качество выпущенной LLaMA, GPU-throughput
или воспроизведение полного предобучения не проверялись.
