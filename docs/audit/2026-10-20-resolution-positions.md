## Проверка объяснений и фактов

| Механизм | Разобранный случай и промежуточные результаты |
|---|---|
| Resize | 1600×1000: растяжение с двумя масштабами, вписывание 336×210 и поля 63+63, центральный crop после масштабирования короткой стороны |
| Бюджет | Четыре размера при P=14 и merge=2; отдельно стоимость ViT до merge и последовательность LLM после него |
| Molmo | Ветка с margins=(4,4): 24 patches, шаг 16, перекрытие входов 8 patches; сетка 2×2 даёт 400 high-res +144 overview векторов, 32 row markers и 4 границы =580 позиций |
| AnyRes | Три холста для 768×384; эффективная площадь и padding; две сетки 27×27 переставляются в 27×54 |
| AnyRes budget | 1458 локальных +27 newlines +729 overview =2214; при K=1 интерполяция в 19×38 и итог 1470 |
| InternVL grid | Одинаковые пропорции 2:1 при разных площадях дают 4×2 и 2×1; thumbnail увеличивает число входов до 9 и 3 |
| Pixel unshuffle | 4×4×1 →2×2×4, первый блок [0,1,4,5], обратная перестановка; векторизация не объявлена усреднением |
| Qwen resize | 1000×1600 →784×1260; 5040 patches ViT →1260 merged vectors; предел площади не обязан заполняться |
| Pixtral | 2×3 patches дают 6 visual +2 markers; 3×2 дают 6+3. Для изображений из 12 и 4 patches маска содержит два независимых блока |
| Сжатие | Два разных диагональных рисунка дают одинаковое среднее; конкатенация и attention pooling отделены от усреднения |
| MRoPE IDs | Prefix 0/1/2, сетка 2×3 со смещением 3, suffix 6/7; 11 cache positions, следующий rotary index 8, delta -3 |
| Rotary | Поворот трёх пар и сохранение dot product при общем сдвиге; не выдано за инвариантность всей VLM |
| Qwen3 frequencies | По коду section=[24,20,20]: 24/20/20 частотных пар; не буквальное равномерное t,h,w на всём диапазоне |
| Координаты | Рамка (112,56,312,156) после resize/padding и (32,16,232,116) в crop обе возвращаются в (200,100,600,300) |
| Window attention | 32×32 patches: 16 окон по 64; 65 536 пар вместо 1 048 576 для полного слоя, без проекций/FFN |

Уточнения, внесённые вместо прежних обобщений:

- В статье Qwen2-VL число 66 имеет явное объяснение: 64 visual
  features и две служебные границы. Это не гипотеза о неизвестном processor.
- Число 36 у InternVL не является единым пределом всех обучающих примеров.
- Формулировка margin в Molmo сопоставлена с обеими сторонами полей в коде;
  56 px не выданы за полный overlap выбранной ветви.
- Схематическая формула OneVision не выдана за точный строгий лимит prefix.
- MRoPE не подменяет cache_position; Pixtral RoPE-2D в ViT
  не выдан за MRoPE языкового decoder.
- Координатное преобразование обращает сохранённую геометрию,
  а не удалённую пиксельную информацию.
- По видимой человеку цифре не делается недоказанный вывод,
  что её сохранили скрытые признаки encoder.

## Стиль

no-ai-slop проверен отдельно от объяснений. Удалены редакционные
указания о том, какое «умственное действие» должен выполнить читатель,
повторный обзор MRoPE и декларации без вычислительных шагов.
Сохранены необходимые термины, математические сравнения, ограничения,
источники и все исходные смысловые иллюстрации.

Полные английские лекции не переводились и не заменялись новым
переводом; английский раздел не менялся. Русская глава содержит
проверяемое объяснение механизмов и явно заданные учебные примеры,
а не воспроизведение защищённых исходных глав целиком.
