## Исполнение и найденная численная граница

Команда финальной проверки:

```sh
uv run --offline --with torch==2.14.1 --with transformers==4.57.1 \
  --with numpy==2.3.5 python publishing/tools/check_kv_cache_examples.py
```

Checker исполняет все пять actual Python-блоков главы по порядку и проверяет,
что ни один Python-fence не пропущен. Настоящая Llama содержит 5200 случайных
параметров. Максимальная ошибка логитов на пяти разбиениях —
`2.9802322387695312e-08`; кеши всех слоёв также совпадают с полным проходом.
Ручной greedy совпал с настоящим generate. У кеша формы (1,2,6,4) в каждом
из двух слоёв реально учтены 768 байт float32 K/V.

Отрицательные контроли не принимают ошибочный результат за эквивалентность:

- сброс RoPE-позиций нового куска: max error `0.00016921013593673706`;
- пропуск position_ids после правильно пронумерованного padded-prefill:
  `0.00018456578254699707` у короткой строки; длинная строка не меняется;
- повторная передача всего префикса вместе с прошлым кешем: длина девять
  вместо шести и несовпадающие логиты;
- неверная causal-диагональ SDPA, независимая нормировка блоков и чтение
  незаполненных слотов также не проходят проверку правильного результата.

Первый FP64-вариант нового примера дал NaN при левом padding. Причина
воспроизведена сменой только dtype и сверена с кодом: eager_mask создаёт
конечный finfo(float64).min, а eager attention считает softmax в float32.
Полностью закрытая строка превращается в [-inf,...], softmax даёт NaN;
во втором слое NaN уже попали в K/V padding-позиций. Тот же пример в float32
проходит. Глава явно использует float32 для настоящей Llama; checker проверяет
конечность всех padded K/V и логитов. Отдельно воспроизводится сама граница
FP64→FP32 softmax. Библиотека не патчилась; это не заявление об исправлении
всех dtype/backend вариантов. Изолированный математический пример attention
по-прежнему работает в float64.

Финальный лог `/var/tmp/bookvar-kv-cache-examples-2026-10-25.log` содержит
SHA главы выше. Веса и датасеты не скачивались; GPU, обученная модель,
