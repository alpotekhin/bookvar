`publishing/tools/check_kv_cache_examples.py` executes both actual Markdown
blocks. PASS on CPU, PyTorch 2.14.1:

- five chunk partitions, every cached prefix, independent SDPA comparison;
- negative control: non-square upper-left causal mask differs from correct
  final-position decode and returns only the first value in this one-query case;

  block softmax equal to contiguous attention;

These checks do not test a full model, GQA/RoPE, GPU attention kernels,
