Обнаружены и исправлены следующие места.

1. В старой сравнительной таблице целью дерева любого бустинга были
   «исправления». Это противоречило предшествующему выводу AdaBoost:
   классификатор там предсказывает исходный класс с изменёнными весами.
   Теперь bagging, бинарный AdaBoost и GBDT разделены на три строки;
   пояснение связывает их с полными разборами выше.
2. Начальная константа была использована в ручном примере, но её общий
   выбор не был выведен. Добавлена минимизация суммы потерь и вывод
   среднего для квадратичной ошибки. Показано, что константа остаётся
   в сумме после добавления деревьев.
3. Классификационный пример начинался с нулевого логита без разбора
   неравных долей классов. Теперь выведено начальное отношение шансов,
   посчитаны логит и все псевдоостатки для двух единиц из десяти меток.
   Нулевой старт отделён от старта по долям классов. В следующем абзаце
   явно указано условие F₀=0 для чисел 1+1 → 2 → σ(2).
4. Для минимума квадратичного приближения по значению листа указано
   условие положительной суммы кривизны и регуляризации.
