## Исправленные содержательные ошибки

1. `evaluation_quiz_precision_recall_C1.svg` показывал границу классификации
   при определённом коэффициенте регуляризации. Это не смена порога одной
   модели и не PR-кривая. В главе теперь реальные PR/ROC-панели MOOC;
   исходный файл курса сохранён.
2. У двух положительных объектов нельзя получить пять стратифицированных
   проверочных частей, содержащих положительный класс каждая.
   Невозможность и неопределённые метрики разобраны явно.
3. Случайный уровень ROC-AUC 0,5 отделён от нижней границы 0.
   Соответствующее неверное утверждение оригинального урока не перенесено
   в каноническое изложение; сохранённый английский оригинал не переписан.
4. Настройка порога по OOF отделена от независимой проверки этого порога.
   OOF не устраняет оптимизм последующего выбора по тем же меткам.
5. AP отделена от трапецеидального интеграла PR; частота класса — точный
   AP постоянного прогноза, но не обязательный AP любого конечного
   случайного ранжирования.
6. Калибровка отделена от допустимого диапазона [0,1], ранжирования,
   Brier score и решения с заданной ценой ошибок.
7. Уточнены среднее train против среднего eval в R² и соглашение о
   квантилях дискретного bootstrap. Прежние границы −1 и 1/2 соответствуют
   inverse empirical CDF; NumPy по умолчанию интерполирует иначе.

## Проверка объяснений

| Механизм | Опора и разобранный пример |
|---|---|
| Матрица ошибок | MOOC Classification; 100 объектов, два порога, явный порядок labels=[0,1] |
| Precision/recall/BA/F1 | Счётчики из того же примера, нулевые знаменатели, micro/macro 8:2 |
| PR и AP | Перебор всех различных оценок; AP = 5/6, группы равных scores |
| ROC-AUC | Сравнение 196 пар; 195/196, противоположное ранжирование даёт 0 |
| Решение по цене | Сопоставление ожидаемых затрат; вывод порога C_FP/(C_FP+C_FN), границы применимости |
| Ограничение мощности | 500 проверок, precision@500 = 0.2, recall@500 = 0.5 |
| Калибровочная кривая | Точка (0.75,0.5), две записи не устанавливают систематическую ошибку |
| Калибраторы | Сигмоида с заданными коэффициентами и объединение изотонических блоков 0,1,0,1 → 0,.5,.5,1 |
| Вероятностные потери | Brier .017 против .0196; уверенные ошибки в log loss |
| CV и зависимости | Iris, два редких объекта, целые группы, временной зазор |
| OOF-агрегирование | Среднее F1 .6 против pooled F1 1/3; разные шкалы моделей для pooled AUC |
| Вложенный выбор | Внешние 40/10 и внутренние 30/10; выбор C и порога внутри внешней оценки |
| Регрессия | MAE=1, MSE=3, RMSE=√3, R²=−3.5; единицы, median AE, нулевые цели в MAPE |
| Парный групповой bootstrap | Среднее по пациентам −1/18 против среднего по визитам 1/6; полный перебор 27 реплик |

Код `check_evaluation_examples.py` выполняет оба опубликованных блока,
независимо пересчитывает примеры, наблюдает все 120 фактических обучений
StandardScaler и проверяет отсутствие внешних проверочных строк в каждом
из них. Стоимость и ROC-AUC внешних прогнозов пересчитаны вручную по
обученным объектам. Это проверка учебной процедуры, не медицинский эксперимент
и не сравнение производительности.
