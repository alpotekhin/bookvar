## Исполнение

`publishing/tools/check_grpo_examples.py` выполняет все 11 actual Python-fences
канонического файла в исходном порядке. PyTorch 2.14.1, TRL 0.24.0, CPU.
Затем независимо проверяет:

- групповую арифметику, population/sample std, сдвиг и масштаб награды,
  detach, однородные группы и недопустимые входы;
- шесть сочетаний знака преимущества и области clipping, float64 gradcheck;
- удаление padding до exp: NaN, ±inf, ±1e30 не меняют потерю/градиент;
- EOS входит в маску, PAD исключён; ответы имеют разную длину;
- процессные оценки шагов и накопление на неравных микропакетах;
- 1740 исчерпывающих конечногрупповых случаев для REINFORCE, group mean,
  leave-one-out, теоретического MaxRL и практического пропуска K=0;
- числовое различие полного и токенового перевзвешивания;
- градиенты GSPO и Kimi, эквивалентность квадратичной записи Kimi;
- параметры настоящего GRPOConfig, включая CPU и отключённые bf16/fp16.

Команда:

```sh
uv run --offline --with torch==2.14.1 --with transformers==4.57.1 \
  --with numpy==2.3.5 --with trl==0.24.0 \
  python publishing/tools/check_grpo_examples.py
```
