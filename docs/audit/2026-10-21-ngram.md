| Механизм | Сохранённая постановка и конкретный случай |
|---|---|
| Chain rule / Markov | Три условных множителя без предположения независимости; одинаковое последнее слово против пары токенов |
| Границы | BOS задан, EOS предсказывается; 8 слов + 3 EOS = 11 событий; триграмме нужны два BOS, но не два лишних target |
| Оценка MLE | Таблица переходов одного корпуса; вывод через условное правдоподобие и ограничение суммы; отдельный случай C(h)=0 |
| Текст и префикс | `кот спит`: prefix 4/9, EOS 8/27, оставшееся продолжение 4/27; нового `пёс спит бежит` в train не было, P=1/9 |
| Нули / add-k | Нулевая пара при известном h против 0/0; строка add-one из шести ответов; k=.1, 1/36 и 7/12; пустая строка и OOV |
| Интерполяция | P3/P2/P1 для EOS = 1/2, 2/3, 3/11; веса .6/.3/.1 дают 29/55; отсутствующая строка и перенормировка весов |
| Backoff | Наивная сумма 16/11; освобождение 1/3 массы, alpha=11/15 и распределение только среди невиданных ответов |
| Stupid Backoff | Сумма 13/11 при .4; ранжирующие scores не выданы за вероятности или PPL |
| Kneser–Ney | Восемь типов пар против 11 употреблений; continuation, D=.5, все шесть ячеек и сумма 1 |
| Поддержка и рекурсия | Нулевой unknown; пример равномерной компоненты даёт 1/180; continuation count 2 вместо raw 101; исключение BOS |
| PPL | `пёс спит EOS`: 2/9, N=3, NLL .501359, PPL 1.650964; без EOS другое число; log bases, underflow и corpus aggregation |
| Генерация | CDF для BOS и следующей строки; sampling против greedy; seed; EOS против технического лимита; геометрический цикл |
| Порядок и обобщение | Для D2 триграмма улучшает train 2/9→1/3, но обнуляет новое продолжение, которому биграмма давала 1/9 |

Код KN — законченный биграммный пример с фиксированным D,
не объявленный реализацией полного modified Kneser–Ney или Katz.
Для старших порядков сохранены механизм adjusted counts, границы и ссылки
на полный алгоритм. Фиксированное окно MLP не объявлено автоматически снятым
при замене счётчиков нейросетью.

## Исполнение и редактура

`publishing/tools/check_ngram_examples.py`: PASS.
Все шесть опубликованных блоков выполнены независимо в новых namespaces.
Отдельно проверены точные Fraction-расчёты, нормировка всех строк,
trigram/BOS, сумма поддерживаемых законченных текстов,
mixture interpretation add-k, fallback, положительное основание KN,
PPL/энтропийные единицы/агрегация, CDF и выбор 50 000 токенов по весам.
Последнее — проверка учебной процедуры, не benchmark.

Первый запуск нашёл реальную ошибку опубликованного KN-кода:
`max(Fraction(...), 0) / total` мог превратить нулевой вклад во float.
Исправлено на `F(0)`, точные равенства теперь проходят.
В PPL-коде отдельно проверены пустые данные, неверные вероятности, NaN
и переполнение exp при конечной NLL. Вычисление log P остаётся конечным
даже при underflow произведения.

Отдельный no-ai-slop / eval.md проход с академическими оговорками:
удалён прежний абзац о «статистической силе», сохранены выводы и ограничения;
уточнены русская терминология дисконтирования и среднее именно log probabilities,
а не вероятностей. После содержательной правки выполнено полное повторное чтение.
