## Приёмка объяснения

| Механизм | Источник | Проверенный пример и промежуточные шаги |
| --- | --- | --- |
| Последовательный residual-блок | CS336 §3.4–3.5; Llama 3 block | Два нормализованных входа, два сложения, независимые параметры. FFN читает H, остаточная ветвь сохраняет ненормализованный вход. |
| Parallel layers | PaLM §2 | Формула обеих ветвей от одного Z; отдельный скалярный случай 6 против 3 при N=I. Не назван простой перестановкой или универсальным ускорением. |
| Формы и группы | Llama 3 Attention/repeat_kv; GQA | Один пакет, три строки, d=4, две Q/одна KV; далее группы Q0/Q1→KV0 и Q2/Q3→KV1. Явная смена B,H,T,D → B,T,H,D перед объединением. |
| Attention целиком | CS336; Llama 3 | Заданные X и проекции, RMS, обе вращённые Q, общие K/V, две разные строки scores/softmax, две суммы V и первое residual-сложение. |
| FFN | CS336 §3.4.2; исходный FeedForward | Две ветви ширины 6, SiLU и произведение, возврат в 4, численные H/R2/F/Y. Нет обращения к соседним строкам. |
| Cache и причинность | Llama 3 Attention/Transformer | Сохранение K/V именно каждого слоя, глобальные RoPE-позиции, full = prefix + suffix из двух позиций, маска [[1,1,0],[1,1,1]]. |
| Память и параметры | CS336 resource accounting; Lecture 3 57–63 | 48+72+8=128 параметров, 12 чисел/96 байт cache; отличены Q-head cost, KV storage, временные повторы и память всего процесса. |
| Local/sparse | Lecture 3 64–66; Mistral config | Окно 2, перенормировка весов и новый численный Y, путь 0→1→2 через два слоя, L(w−1), чередование с полными слоями. Учебная плотная маска не выдана за экономный kernel. |
| GPT-2/LLaMA | Ранее проверенные первичные code/paper; Alammar | Pre-norm уже у GPT-2, исходная LLaMA MHA во всех размерах, отдельные нормы/позиции/FFN/bias/tying. Схема Alammar не используется для восстановления скрытых норм. |
| Ширина FFN | CS336; Kaplan; pinned configs | 2df против 3df, 8d/3, реальные 2048/13696/14336/65536; half-width поля исходного Qwen проверена по config и коду. |
| Головы и глубина | CS336; исходные T5 gin; Tay | T5-11B 128×128 при d1024; точные 24 слоя на стек и d/L=42.7; 3.6B/3.8B counterexample с negative log-PPL и SuperGLUE 76.5/79.9. |
| Словарь | Pinned configs; размеры матриц | 262144000 untied весов, условный пример 100/80 токенов, поля 32128/152064/32000 не выданы за число обычных токенов tokenizer. |
| Dropout/WD | T5 released_checkpoints; LLaMA; D'Angelo §3 | 0 pre-training против config/fine-tuning 0.1 у T5.1.1, шаг 2→1.9998 и границы экспериментов AdamW/FP32/BF16. |

Обнаружено расхождение курса с первичной конфигурацией:
слайд aspect ratio таблицы указывает T5-11B около 33, но gin задаёт
d_model=1024 и num_layers=24, то есть около 42.7 на стек.
В главе оставлены первичные размеры. Сам оригинальный слайд таблицы
не редактировался и не копировался вместо проверенной конфигурации.

Удалены псевдокод с неопределёнными функциями, заявление о едином
инварианте всех decoder-only и общие редакционные выводы без механизма.
При no-ai-slop-проходе не сокращались рассуждения, примеры, формулы,
оговорки и исходный английский фрагмент.

## Численная проверка

`publishing/tools/check_decoder_block_examples.py` исполняет ровно
один полный блок Python из текущей главы на CPU.
Окружение — `/tmp/bookvar-imbalance-venv/bin/python`.
Лог: `/tmp/bookvar-decoder-examples-final.log`.

- Все промежуточные тензоры сверены с NumPy/скалярным расчётом
  по отдельным позициям и головам, независимо от Torch forward.
- Проверены центральные разности 128 параметров и 12 входных чисел.
  Максимальная абсолютная ошибка — 8.418044039615324e-11.
- Варьируются MHA/GQA, 1/2/3 KV-головы, B=2, d_h=2/4,
  несовпадение h_q*d_h с d и четыре окна None/1/2/4.
- Проверены все 16 разбиений длины 5 для каждого из четырёх вариантов
  размеров и четырёх окон: всего 256 составных cache-проходов.
- Выход attention сопоставлен с PyTorch SDPA с явной разрешающей маской.
- Изменение будущих строк не изменяет ранние выходы.
- Отдельно выявляются неверные repeat вместо repeat_interleave,
  reshape без transpose, перезапуск RoPE и квадратная маска.
- Реальные тела четырёх функций закреплённой Llama 3 исполняются
  отдельно без импорта CUDA/fairscale; repeat_kv и RoPE сопоставлены
  с нашей раскладкой. Полная выпущенная CUDA-модель не запускалась.
- Проверены первичные config-поля, класс QWenMLP, исходные T5 gin,
  арифметика памяти, словаря, WD и последовательной/параллельной композиции.

Учебная модель не оценивает качество языка, GPU-throughput,
пиковую память serving или обучение выпущенных весов.
