# Исполненный код

publishing/tools/check_sft_examples.py извлекает и исполняет все три
Python-блока именно итогового Markdown, а не отдельную копию реализации.

Среда: macOS arm64, CPU, PyTorch 2.14.1, NumPy 2.3.5,
Transformers 4.57.1. Модель из конфигурации Llama: 6 704 случайных параметра;
предобученные веса и CUDA не используются.

Подтверждено:

- Явный сдвиг совпал с внутренней loss HF; 4.840772 до обновления.
- Правый padding с id=EOS не изменил loss; настоящий EOS остался целью.
- Пустая response mask вызвала ValueError до backward.
- AdamW действительно выполнил первый шаг.
- Градиенты выходных логитов ненулевые только на позициях 4–8.
  Норма градиента prompt embedding ACTIVATIONS после шага — 0.4996343.
  Не использован градиент разделяемой словарной матрицы как ложное
  доказательство зависимости от конкретных позиций запроса.
- Packed B совпал с отдельно обработанным B: max error 4.47035e−08.
  Замена A не изменила B при блоковой маске.
  При обычной причинной маске max change 0.390746: отрицательный контроль.
- Удаление EOS из целей и обучение по всем токенам меняют loss.
- Проверены NLL 0.8419095481, perplexity 2.3207944168,
  токенное/поответное усреднение и численные примеры смеси.

Это тесты правильности одного шага и изоляции внимания.
Полное SFT предобученной модели, качество ассистента, обучение TRL,
GPU kernels и производительность здесь не проверялись.
