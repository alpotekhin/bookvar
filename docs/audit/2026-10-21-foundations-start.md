## Что изменилось в объяснении

| Механизм | Недостаток прежней версии | Текущий разбор |
|---|---|---|
| Числа и формы | Начало предполагало знакомство с attention, loss и residual connections | Матрица двух объектов по три признака вводится до терминов языковой модели |
| Вектор, массив, ранг | Рангом называлось только число осей, без оговорки о ранге матрицы | Различены координаты, ndim, длины осей, число элементов и ранг матрицы |
| Представление текста | Lookup с большими ID без показанной таблицы | Две фразы, словарь из трёх элементов, явная E и полученный массив 2×2×3 |
| Broadcasting | Только общее правило и изображение страницы D2L | Поправки по признакам и по объектам, несовместимая форма, пошаговое выравнивание справа |
| Reduction | Самостоятельного объяснения не было | Суммы и средние по обеим осям, keepdims и вычитание среднего строки |
| Скалярное произведение | Один пример, cosine без ограничения нулевых векторов | Вычисление суммы, изменение длины при неизменном направлении, перпендикулярные и нулевые векторы |
| Линейное отображение | Общая формула без полного произведения | Матрица 2×3 на 3×2, обе новые координаты для каждого объекта и полный ответ |
| Перестановка и reshape | Не показано различие на одних числах | X.T и reshape(3,2) дают одинаковую форму, но разные значения; оговорка о копировании |
| QKᵀ | Только размеры, без конкретного результата | Полная матрица оценок 2×2 и вычисление одной пары строк; квадратный случай не выдаётся за shape error |
| Нормы | Определения и длина 3–4–5 | L1, L2, единичный вектор, нулевой вектор и норма Фробениуса исходной X |

Удалены неподтверждённое утверждение о «большей части ошибок» и повторяющий
итоговый список. Старый якорь `краткие-итоги` сохранён. Переход к
производной указан в тексте и frontmatter. Маски, головы и внимание
снабжены ссылкой на будущую главу, а не выданы за уже известные понятия.

## Примеры

`publishing/tools/check_tensor_foundations_examples.py` запущен
в bundled Python с NumPy 2.3.5. Проверены опубликованный Python-блок,
независимое произведение строк на столбцы через Fraction, lookup целиком,
суммы/средние, четыре ошибки несовместимых форм, нормализация и косинусы,
ранг матрицы отдельно от ndim, разбиение/обратное объединение голов
и пример reshape, который требует копирования.

Это CPU-проверка небольших массивов, не обучение Transformer и не запуск
полного upstream TinyTorch test suite. Сохранённый вывод курса не принят
за собственный результат выполнения.
