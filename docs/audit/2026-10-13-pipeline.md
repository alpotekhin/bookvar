## Corrections

- Removed the known-invalid Harvard timeline. The source SVG remains on
  disk with its withdrawal recorded, not silently repaired or redrawn.
- Replaced full CS336 slide embeds with original GPipe / 1F1B / interleaved
  SVGs from the Apache-2.0 Ultra-Scale Playbook. CS336 content and source-unit
  IDs remain in the chapter; source slide files remain available.
- Made the strict 1F1B table match its pseudocode: live activation peaks are
  4/3/2/1 for p=m=4, rather than the former eager-forward 4/4/3/1 variant.
- Explicitly distinguish idle time / total time from idle time / useful
  work. The same example gives 42.9% and 75%, respectively.
- GPipe and 1F1B diagrams use source timing; the complete textual tables
  declare equal forward/backward durations and zero communication time.
- Memory is a saved-activation estimate, not a measured total GPU peak.
  Fixed microbatch size and fixed global batch size are distinguished.
- Added interleaved placement and bubble arithmetic; no universal divisibility
  claim or hardware speedup. Zero Bubble and DualPipe are connected to
  deferred weight gradients, memory and synchronization costs.
- The 32-GPU configuration uses forward=90ms, backward=180ms: 5.13s in the
  explicitly idealized model. A boundary sends 2GiB each direction per step;
  its 128MiB message size is not confused with memory or the full-step volume.
- Explained sum of tied-weight gradients versus averaging data replicas;
  uneven-token loss normalization and PyTorch 2.14 scale_grads.

## Sources and checks

Re-read the Ultra-Scale Playbook PP section and pinned licence declaration,
Megatron-LM paper section 2.2, GPipe entry, Zero Bubble mechanism and current
PyTorch 2.14 pipeline-schedule documentation. Source links are adjacent to

`check_pipeline_examples.py` passes on PyTorch 2.14.1 CPU:

- Parses and validates both actual chapter timeline tables.
- Independently generates strict 1F1B schedules for p=1..8, m=1..32;
  validates all dependencies, total time and live counts.
- Rejects an early backward and a missing operation.
- Executes the actual two timelines on a four-stage nonlinear model, cutting
  autograd graphs at every boundary and explicitly returning input gradients.
  Outputs, loss, every parameter gradient, input gradient and an SGD update
  agree with the non-partitioned reference; maximum parameter error 1.39e-17.
- Includes a microbatch with zero valid labels and unequal valid-label counts;
  the incorrect mean-of-means normalization is a failing negative control.
- Verifies transfer bytes, times, microbatch arithmetic and memory estimates.

These are single-process CPU simulations, not Gloo/NCCL execution, actual
network overlap, GPU-memory measurements or a throughput benchmark. Browser,
build and link acceptance will be recorded after the distributed-detail
