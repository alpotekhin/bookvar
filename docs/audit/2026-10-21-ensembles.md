## Исправленные содержательные ошибки

1. Серия `boosting_iter_orange*.svg` в прежнем тексте объяснялась
   как обучение GBDT на остатках. Генератор использует
   `AdaBoostRegressor`, а не gradient boosting.
   Серия убрана из этой роли и заменена настоящими рисунками
   notebook Gradient-boosting decision tree.
2. `bagging_trees_predict.svg` относился к классификации,
   хотя подпись описывала регрессионные ступени.
   Теперь механизм показан реальными прогнозами регрессоров.
3. Старые широкие `bagging_reg_grey*.svg` используют
   подвыборки без возвращения, а `bagging_reg_blue.svg`
   строится отдельным BaggingRegressor с другими параметрами.
   Они не выдаются за точную последовательность bootstrap
   и усреднение именно шести показанных деревьев.
4. Устранены обещание монотонного улучшения любой метрики
   при добавлении деревьев и неявное отождествление голосования
   с усреднением вероятностей.
5. Уточнено, что число деревьев не восстанавливает информацию,
   потерянную при необратимом объединении признаков в bins.
6. Выбор лучшей итерации отделён от обнаружения условия остановки.
   Ограничение глубины не описывается как требование симметрии дерева.

Исходные материалы и перечисленные старые рисунки в курсе сохранены.

## Приёмка механизмов

| Механизм | Опора | Проверенный разбор |
|---|---|---|
| Bootstrap | MOOC Bagging, Bootstrap resampling | Пять выборов A,A,C,E,E; кратности и отсутствующие объекты |
| Усреднение | MOOC Bagging, Aggregating | Числа 2,5,8; общая ошибка; реальный рисунок ста моделей |
| Голоса и вероятности | MOOC и документация RF | 0.51,0.51,0.01 дают разные классы при двух правилах |
| Дисперсия среднего | Ковариационное тождество | B дисперсий и B(B−1) ковариаций, числа для двух корреляций |
| Random forest | MOOC Random forests | Новые наборы признаков в каждом узле, отличие Bagging.max_features |
| OOB | MOOC Bootstrap, API | Точная вероятность для n=5, предел, ручной прогноз по отсутствию в draw |
| AdaBoost | MOOC AdaBoost и классический бинарный вывод | Минимум экспоненциальной потери, коэффициент и веса 1/6,1/6,1/6,1/2 |
| Gradient boosting | MOOC Gradient boosting | Полная последовательность двух пней, MSE 5 → 2 → 1 |
| Псевдоостатки | Guide, Mathematical formulation | Отрицательная производная, ограничение класса деревьев, сумма исправлений |
| Классификация | Guide | Логиты против вероятностей, бинарный и трёхклассовый градиенты |
| Второй порядок | XGBoost, Structure Score | Вывод −G/(H+lambda), конкретные листья ±2, штраф и split gain |
| Histogram | MOOC Speeding-up, Guide | Агрегаты G,H, число кандидатов, нижняя граница MSE 1/6 после грубого binning |
| Регуляризация и остановка | MOOC Hyperparameters | Шаг 1 против 1/2, ограничения пней на XOR, лучшая и последняя итерации |
