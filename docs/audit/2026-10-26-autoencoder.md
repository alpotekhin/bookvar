## Сопоставление объяснений с источниками

| Механизм | Прочитанные разделы и проверенный ход объяснения |
|---|---|
| Обычный AE | Weng, Autoencoder и Denoising Autoencoder целиком; UvA, Building the autoencoder. Уточнены сумма по координатам и среднее по пакету. Прямая с четырьмя точками восстанавливается через одну координату; вне прямой точка (1,-1) теряет информацию. PCA связывается с подпространством, не с обязательным совпадением координат кода. |
| Обучение и ограничения кода | Для линейного AE вручную получены потеря 3.2, градиенты -8/-0.8, веса после SGD и потеря .008. Для denoising разделены повреждённый вход и чистая цель. Sparse/contractive AE оставлены связанными дополнительными вариантами, не объявлены полноценно перенесёнными отдельными темами. |
| Свёрточное восстановление | UvA, полные выбранные постановка, Encoder, Decoder, transpose/output_padding и MSE; код двух классов прочитан. C transpose не назван обратной матрицей. Пример даёт (5,8), затем (5,18,16). output_padding меняет форму, причём добавленный результат 2 ненулевой. Указаны размеры всех основных карт и связь tanh с входным диапазоном. |
| MSE и генерация AE | UvA, Why MSE и Generating new images. Условное среднее двух целей уменьшает MSE с 1 до .5, но смешивает объекты. Восстановление входов не определяет известное распределение новых кодов. Не перенесено слишком сильное утверждение, будто KL автоматически делает весь latent space нормальным. |
| Вероятностная модель | AEVB §§2.1–2.4 и Appendix B прочитаны; Weng, Variational Autoencoder/ELBO. Разделены prior, likelihood, marginal, true posterior и amortized inference. Энкодер задаёт семейство приближений, а не доказывает нормальность истинного posterior. |
| ELBO и два KL | Выписаны оба разложения совместной плотности. KL к true posterior является зазором, KL к prior входит в обучающую цель. Для x=2 posterior N(1,.5) получен выделением полного квадрата. При точном posterior зазор равен нулю, KL к prior остаётся .596574. |
| Likelihood и аналитический KL | Appendix B AEVB; класс/loss_function PyTorch examples. KL получен через ожидания квадратов. Разделены Bernoulli mass, мягкие BCE targets и Gaussian likelihood с фиксированной/обучаемой дисперсией. Проверены .980829 reconstruction + .125 KL; reduction нельзя менять только у одного члена. |
| Репараметризация | Полные выбранные AEVB §2.4 и Weng Reparameterization trick. При фиксированном epsilon=-.25 получены z=0, градиенты -.5 и 1.75. Проверены обычный граф производной, независимость шума от параметров, sample/rsample и другие возможные оценки градиента. |
| Код, eval, генерация | Полностью прочитаны VAE и loss_function закреплённого PyTorch примера. Сохранены исходные английские классы, комментарии и docstrings. Объяснено отличие sigmoid+BCE от BCEWithLogits и сумма по всему пакету. eval сохраняет случайный вызов; decode(mean) не равен среднему decode(z). |
| Интерполяция | При повторном чтении обнаружено, что старое название раздела не сопровождалось процедурой интерполяции. Добавлены определение, середина (1,2), пять реальных кодов и вызов исходного декодера. Это редакционный расчёт по определению, а не цитата/эксперимент из UvA. У независимых нормальных концов середина имеет половинную дисперсию; путь не подменяет генерацию из prior. |
| β-VAE и collapse | Weng, Beta-VAE; abstract первичного Locatello et al. для ограничения disentanglement. Из двух кандидатов β=1 выбирает первый, β=4 второй. Для collapse явно построены одинаковые q и постоянный Bernoulli decoder: KL=0 при потере 2 log 2 и отсутствии информации о входе. Указаны ограничения этих выводов. |
