# Численные проверки

Старый NumPy-checker выполнен заново. Он проверил прямой/обратный проход
нелинейных экспертов, TP=1/2/3, перестановки, распределение 1024 координат,
16384 назначения, точные сообщения и нормировку DP/EDP.
Максимальные ошибки конечных разностей x/W1/W2/router:
4.58e-10 / 1.37e-9 / 5.84e-10 / 8.51e-10.
Это симуляция алгебры, не 1024 реальных процесса.

Новый publishing/tools/check_expert_parallel_distributed.py извлекает
оба актуальных Python-блока главы. На PyTorch 2.14.1 запущены два
реальных CPU/Gloo-процесса: исполнены сами инициализация, исходный
forward/backward и завершение из второго блока. Затем проверены:

- неравномерная маршрутизация;
- пустой получатель и его эксперты;
- отправитель без локальных токенов;
- обучаемый top-2 softmax-маршрутизатор.

Выходы, градиенты входов, коэффициентов, локальных матриц и суммарный
градиент реплик маршрутизатора совпали с полным нераспределённым расчётом
при rtol=atol=1e-11. Явно задана глобальная сумма, без скрытого деления
на размер группы. Checker подтвердил итоговый hash ccead0e7…128672b.
CPU-проверка не доказывает GPU-производительность, NCCL, перекрытие
связи с вычислениями или работу Megatron на кластере.
