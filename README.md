# Bookvar

Bookvar (Букварь) — открытый русскоязычный учебник по машинному и глубокому
обучению: от градиента и нейронных сетей до современных LLM, RAG и агентных
систем.

Содержательные Markdown-файлы одновременно открываются в Obsidian и
публикуются как статический сайт на Astro Starlight. Каталог `site` не является
второй копией учебника: перед сборкой адаптер преобразует Obsidian-ссылки,
вложения и callouts во временное дерево страниц.

## Предварительная версия

Разработка и Pages-preview пока ведутся в ветке `dev`. Содержимое находится в
активной редактуре и не считается стабильным изданием.

## Локальный запуск

Требуются Node.js 22.12+ и pnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm --dir site dev
```

Проверка, эквивалентная CI:

```bash
pnpm --dir publishing check:topics
pnpm --dir publishing test:unit
pnpm --dir site check
pnpm --dir site build
pnpm --dir publishing test:output
```

После сборки отдельно проверьте внутренние адреса, якоря и файлы:

```bash
pnpm --dir publishing check:links
```

Команды для обновления указателя тем, локального preview и проверки пути
GitHub Pages приведены в [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Совместное редактирование

Правки принимаются pull request-ами в ветку `dev`; из неё же GitHub Actions
собирает Pages-preview. Подробный порядок работы в Obsidian, требования к
главам, источникам и иллюстрациям описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Устройство материалов

- `00 Учебник` — полные объяснения в последовательном порядке;
- `01 Справочник` — предметный указатель к тем же главам, моделям,
  сравнениям и хронологии технологий;
- `02 Атлас моделей` — исходники страниц о семействах и версиях моделей,
  опубликованных внутри справочника;
- `03 Исследовательские линии` — исходники «Обзоров направлений» внутри
  справочника;
- `04 Вопросы` — указатели вопросов со ссылками на ответы;
- `05 Источники` — библиотека оригинальных статей и курсов, разборы
  реализаций и реестр иллюстраций;
- `06 Практика` — код, лаборатории и интерактивы;
- `publishing` — адаптер Obsidian Markdown для сайта;
- `site` — оболочка Astro Starlight.

У каждого механизма одно полное объяснение в учебнике. Новые проверенные
факты, примеры и рисунки дополняют эту главу. Оригинальные курсы сохраняют
свои оглавления в библиотеке источников; отдельного основного маршрута
для каждого курса нет. Старые справочные URL после проверенного объединения
ведут прямо к каноническому объяснению.

Материалы могут сохранять язык оригинала. Наличие английского интерфейса
не означает, что весь учебник переведён; существующие английские главы
проверяются вместе с изменениями их канонических версий.
Локальный каталог `raw` намеренно не публикуется.

## Права на материалы

Репозиторий содержит авторский текст и иллюстрации из внешних источников с
отдельной атрибуцией. Единая лицензия для всего репозитория пока не объявлена:
перед повторным использованием конкретного изображения проверяйте его запись в
реестре источников.
