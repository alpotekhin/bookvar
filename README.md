# Bookvar

Bookvar (Букварь) — открытый русскоязычный учебник по машинному и глубокому
обучению: от градиента и нейронных сетей до современных LLM, RAG и агентных
систем.

Содержательные Markdown-файлы одновременно открываются в Obsidian и
публикуются как статический сайт на Astro Starlight. Каталог `site` не является
второй копией учебника: перед сборкой адаптер преобразует Obsidian-ссылки,
вложения и callouts во временное дерево страниц.

## Предварительная версия

Разработка и Pages-preview пока ведутся в ветке `dev`. Содержимое находится в
активной редактуре и не считается стабильным изданием.

## Локальный запуск

Требуются Node.js 22.12+ и pnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm --dir site dev
```

Проверка, эквивалентная CI:

```bash
pnpm --dir publishing test:unit
pnpm --dir site check
pnpm --dir site build
pnpm --dir publishing test:output
```

## Устройство материалов

- `00 Учебник` — последовательный маршрут;
- `01 Справочник` — механизмы и определения;
- `02 Атлас моделей` — семейства и версии моделей;
- `03 Исследовательские линии` — развивающиеся направления;
- `04 Вопросы` — указатели вопросов со ссылками на ответы;
- `05 Источники` — статьи, курсы и реестр иллюстраций;
- `06 Практика` — код, лаборатории и интерактивы;
- `publishing` — адаптер Obsidian Markdown для сайта;
- `site` — оболочка Astro Starlight.

Локальный каталог `raw` намеренно не публикуется.

## Права на материалы

Репозиторий содержит авторский текст и иллюстрации из внешних источников с
отдельной атрибуцией. Единая лицензия для всего репозитория пока не объявлена:
перед повторным использованием конкретного изображения проверяйте его запись в
реестре источников.
