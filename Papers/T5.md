# Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer (T5)

**Authors:** Colin Raffel, Noam Shazeer, Adam Roberts, Katherine Lee et al. (Google)
**Published:** 2020 (Journal of Machine Learning Research 21; arXiv:1910.10683v4)
**URL:** https://arxiv.org/abs/1910.10683

## TL;DR

T5 (Text-to-Text Transfer Transformer) — систематическое исследование, которое переводит **все NLP задачи в единый формат text-to-text** (вход и выход всегда строки) и проводит масштабный ablation study: архитектуры, unsupervised objectives, данные, transfer approaches, масштабирование. Главный вывод: комбинация деноизинг pre-training + [[02 Areas/ML & DL/Concepts/Architectures/Encoder-Decoder|Encoder-Decoder]] архитектуры + C4 данных + scale даёт SOTA на 18/24 задачах (при 11B параметрах). Попутно авторы создают **C4** (Colossal Clean Crawled Corpus) — стандартный датасет для pre-training.

## Problem

К 2019 году пространство transfer learning для NLP разрослось настолько, что стало сложно сравнивать разные подходы: разные pre-training objectives (MLM, LM, Span extraction), разные архитектуры (encoder-only, decoder-only, encoder-decoder), разные датасеты, разные transfer strategies (full fine-tuning, adapters, проч.). Нет единой системы для честного сравнения.

T5 устанавливает единую базу: **text-to-text framework** — любая задача это `(text input) → (text output)`. Это позволяет использовать один и тот же model, loss function, decoding procedure и hyperparameters на всех задачах.

## Method

### Text-to-Text Framework

Каждая задача кастуется в текст-в-текст через **task prefix** (Figure 1):
- Перевод: `"translate English to German: That is good."` → `"Das ist gut."`
- Классификация: `"cola sentence: The course is jumping well."` → `"not acceptable"`
- NLI: `"mnli premise: ... hypothesis: ..."` → `"entailment"`
- Summarization: `"summarize: [article]"` → `[summary]`
- Regression (STS-B): округляется до 0.2 increments, конвертируется в строку → `"3.8"`

### Architecture

**Baseline:** стандартный [[02 Areas/ML & DL/Concepts/Architectures/Encoder-Decoder|Encoder-Decoder]] Transformer (Vaswani et al., 2017) с модификациями:
- Layer norm **без аддитивного bias** (rescale only)
- Layer norm вне residual path (до sub-layer, не после)
- **Relative position embeddings** (не абсолютные): скаляр, добавляемый к attention logit. 32 buckets, логарифмические диапазоны до offset 128. Shared across layers (но разные per head).
- Dropout 0.1 везде

**Baseline параметры:** encoder + decoder, каждый похож на BERT-Base (12 слоёв, d_model=768, 12 heads, dff=3072). Итого ~220M параметров.

**Ключевой результат ablation архитектур (Section 3.2):** Encoder-Decoder **лучше** decoder-only (LM) и encoder-only (BERT-like) на text-to-text framework при сопоставимом числе параметров. Shared Encoder-Decoder (parameter sharing) — почти не теряет на качестве, но вдвое меньше параметров.

### C4 — Colossal Clean Crawled Corpus (Section 2.2)

Common Crawl (апрель 2019) → очистка:
- Только строки с terminal punctuation (`.`, `!`, `?`, `"`)
- Минимум 3 предложения, 5 слов в строке
- Удалены страницы со словами из "dirty words" list
- Удалён "lorem ipsum", JavaScript, `{`, citation markers
- Удалены privacy/cookie policy строки
- Дедупликация на уровне трёх предложений
- Языковая фильтрация: только английский (langdetect p≥0.99)

**Итог: ~750GB чистого английского текста.** Стал стандартным датасетом для pre-training.

### Pre-training Objective

**Baseline denoising objective (Section 3.1.4, Figure 2):**
- 15% токенов случайно заменяются sentinel tokens
- Consecutive spans → один sentinel (`<X>`, `<Y>`, ...)
- Target = dropped-out spans через те же sentinels + финальный sentinel

Пример: `"Thank you <X> me to your party <Y> week."` → `"<X> for inviting <Y> last <Z>"`

**Результат ablation objectives (Section 3.3):** Большинство denoising objectives работают примерно одинаково. Лучший = sentinel-based span corruption. Авторы рекомендуют objectives с короткими target sequences для compute efficiency.

### Training Details

| Параметр | Pre-training | Fine-tuning |
|---------|-------------|------------|
| Шаги | 2^19 = 524,288 | 2^18 = 262,144 |
| Batch size | 128 последовательностей × 512 токенов | то же |
| Токенов | ~34B (2^35) | - |
| LR schedule | Inverse square root | Constant 0.001 |
| Optimizer | AdaFactor | AdaFactor |

Vocabulary: SentencePiece (WordPiece), 32K, shared input/output. Включает немецкий, французский, румынский (для WMT).

## Key Results (Table 14)

### GLUE (test set)

| Модель | Average |
|--------|---------|
| Previous best | 89.4 |
| T5-Small | 77.4 |
| T5-Base | 82.7 |
| T5-Large | 86.4 |
| T5-3B | 88.5 |
| **T5-11B** | **90.3 ✓** |

T5-11B устанавливает SOTA на GLUE: 90.3 (превыша previous SOTA 89.4). Особенно сильно на MNLI-m (92.2 vs 91.3) и RTE (92.8 vs 89.2).

### SuperGLUE (test set)

| Модель | Average |
|--------|---------|
| Previous best | 84.6 |
| Human | 89.8 |
| T5-3B | 86.4 |
| **T5-11B** | **88.9 ✓** |

T5-11B почти достигает human performance (88.9 vs 89.8)! На ReCoRD и MultiRC — **превышает** human performance (возможно bias в метрике).

### SQuAD (Exact Match, validation)

| Модель | EM |
|--------|---|
| Previous best | 90.1 |
| **T5-11B** | **91.26 ✓** |

+1.2 EM над SOTA — значительный рывок на давно установившемся бенчмарке.

### CNN/Daily Mail summarization (ROUGE-2)

| Модель | ROUGE-2 |
|--------|---------|
| Previous best | 20.30 |
| **T5-11B** | **21.55 ✓** |

### WMT Translation

Не достигает SOTA (без backtranslation и cross-lingual pretraining). EnDe: T5-11B 32.1 vs SOTA 33.8.

### Ablation: Scale Effect (Section 3.6, Table 15)

| Модель | GLUE | SQuAD | SuperGLUE |
|--------|------|-------|-----------|
| Baseline (34B tokens) | 83.28 | 80.88 | 71.36 |
| Baseline-1T (1T tokens) | 84.80 | 83.01 | 73.90 |
| **T5-Base (1T tokens + все улучшения)** | **85.97** | **85.44** | **75.64** |

Вывод: scale важен, но **non-scaling improvements** (архитектура, objective, данные) тоже дают независимый прирост.

**T5 побеждает на 18 из 24 задач.**

## Key Takeaways (авторские, Section 4)

1. **Text-to-text works** — единый формат не хуже задача-специфичных архитектур при достаточном scale
2. **Encoder-decoder лучше** для обобщённых NLP задач, чем encoder-only или decoder-only
3. **Denoising objectives** примерно эквивалентны; выбирай efficient (короткий target)
4. **Данные имеют значение** — C4 превосходит unlabeled данные без очистки
5. **Scale доминирует** — 11B модель выигрывает почти везде, но non-scaling factors тоже важны

## My notes

- T5 — это **научная статья-survey**, не просто разработка модели. Ценность в систематическом исследовании, а не только в T5-11B результатах.
- C4 стал стандартным датасетом для pre-training почти всех последующих LLM (включая LLaMA).
- **Sentinel-based span corruption** — более эффективная альтернатива BERT-style MLM: короткий target, меньше compute.
- Relative position embeddings (T5-style) стали одной из стандартных альтернатив RoPE для encoder-decoder архитектур.
- T5 открыл путь к Flan-T5 (instruction tuning) и многим seq2seq LM для генеративных задач.
- "Quality is more important than scale for data" — урок из ablation pre-training data (Section 3.4): filtered C4 >> unfiltered Common Crawl.
