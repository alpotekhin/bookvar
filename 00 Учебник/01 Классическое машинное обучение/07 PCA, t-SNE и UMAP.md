# PCA, t-SNE и UMAP — что именно сохраняет проекция

Когда набор объектов изображают точками на плоскости, часть исходной геометрии
неизбежно теряется. Разные методы сохраняют разные свойства данных.
PCA ищет линейное подпространство с
наименьшей ошибкой восстановления. t-SNE старается не разлучить ближайших
соседей. UMAP сначала описывает локальные соседства графом, а затем воспроизводит
его связи при размещении точек в пространстве меньшей размерности.
Расстояния и площади на трёх полученных картах имеют разный смысл.

Пусть строки $X\in\mathbb R^{n\times d}$ — наблюдения, а
$Z\in\mathbb R^{n\times m}$, $m\ll d$, — их новое представление. До запуска
алгоритма нужно ответить на два вопроса:

1. что означает расстояние между объектами: евклидово, косинусное,
   расстояние между распределениями или другое;
2. нужна ли проекция для сжатия и последующего моделирования либо только для
   исследовательской визуализации.

## PCA: наилучшая линейная реконструкция

### От центрирования к главным направлениям

Сначала из каждого признака вычитают его среднее. Вектор средних
$\mu\in\mathbb R^d$ сохраняют, чтобы затем обработать новые объекты или
вернуться к исходным единицам:

$$
\mu=\frac1n\sum_i x_i,\qquad X_c=X-\mathbf1\mu^\top.
$$

Для центрированной матрицы
PCA выбирает ортонормированные столбцы
$W=[w_1,\ldots,w_m]\in\mathbb R^{d\times m}$:

$$
\begin{aligned}
Z&=X_cW,\\
\hat X&=ZW^\top+\mathbf1\mu^\top.
\end{aligned}
$$

$Z$ содержит координаты объектов в новом базисе. При $m<d$ из $Z$ нельзя
восстановить потерянные направления; $\hat X$ — ортогональная проекция
с добавленным обратно средним. Оптимальное подпространство решает задачу

$$
\min_{W^\top W=I}\|X_c-X_cWW^\top\|_F^2.
$$

Тот же $W$ максимизирует дисперсию проекций:

$$
\max_{W^\top W=I}\operatorname{tr}(W^\top X_c^\top X_cW).
$$

Для каждой точки проекция и остаток ортогональны, поэтому по теореме
Пифагора сумма квадратов длин раскладывается на две части:

$$
\begin{aligned}
\|X_c\|_F^2&=\|X_cW\|_F^2\\
&\quad+\|X_c-X_cWW^\top\|_F^2.
\end{aligned}
$$

Левая часть от выбора $W$ не зависит. Минимизация остатка равносильна
максимизации первой части. Для одного направления $w$ она равна
$w^\top X_c^\top X_cw$. При условии $w^\top w=1$ максимум достигается
на собственном векторе с наибольшим собственным значением.
Следующее направление выбирают ортогональным первому и так далее.
В отличие от спектральной кластеризации, здесь нужны большие собственные
значения матрицы рассеяния, а не малые значения лапласиана графа.

На рисунке полупрозрачные точки находятся в исходной плоскости,
насыщенные точки — на одной прямой после обратного преобразования.
Отклонение вдоль прямой
сохраняется, перпендикулярное ей отбрасывается. PCA минимизирует именно
сумму квадратов этих перпендикулярных отклонений. В обычной регрессии
одного признака по другому ошибки измерялись бы вдоль выбранной
зависимой координаты; задачи оптимизации различаются.

На практике PCA вычисляют через SVD:

$$
X_c=U\Sigma V^\top.
$$

Первые $m$ столбцов $V$ становятся главными направлениями, координаты равны
$Z=U_m\Sigma_m$, а дисперсии компонент пропорциональны
$\sigma_1^2,\ldots,\sigma_m^2$. Если ковариацию вычисляют с делителем
$n-1$, собственное значение равно $\lambda_j=\sigma_j^2/(n-1)$.
Поэтому доля дисперсии — это $\sigma_j^2/\sum_r\sigma_r^2$, а квадрат
оптимальной ошибки реконструкции равен $\sum_{r>m}\sigma_r^2$.

SVD позволяет не строить $X_c^\top X_c$. При полном столбцовом ранге
число обусловленности этой матрицы равно квадрату числа обусловленности
$X_c$, что ухудшает вычисление малых направлений. В API доступны разные
решатели; `svd_solver="full"` ниже фиксирует полное SVD для небольшого примера.

### Численный пример

Рассмотрим уже центрированные точки

$$
X=
\begin{bmatrix}
-2&0\\
0&-1\\
0&1\\
2&0
\end{bmatrix}.
$$

Матрица рассеяния диагональна:

$$
X^\top X=
\begin{bmatrix}
8&0\\
0&2
\end{bmatrix}.
$$

Первое главное направление $w_1=(1,0)^\top$, второе — $(0,1)^\top$.
Одномерный код равен $z=(-2,0,0,2)^\top$. После обратного преобразования две
средние точки обе реконструируются как $(0,0)$; их отклонения по второй
координате утрачены. Квадрат ошибки равен $1^2+1^2=2$ — ровно отброшенному
собственному значению матрицы рассеяния. Доля объяснённой дисперсии первой
компонентой равна $8/(8+2)=0{,}8$.

Доля 0,8 относится к сумме квадратов отклонений, а не к доле сохранённых
классов или предсказательной информации. Например, если целевая метка
зависит от знака второй координаты, первая компонента сведёт две точки
с разными метками в один код $z=0$. Большая объяснённая дисперсия
сама по себе не гарантирует пригодности проекции для классификации.

```python
import numpy as np
from sklearn.decomposition import PCA

centered = np.array([[-2, 0], [0, -1], [0, 1], [2, 0]], dtype=float)
data = centered + np.array([10, 20])
mean = data.mean(axis=0)
Xc = data - mean
U, singular_values, Vt = np.linalg.svd(Xc, full_matrices=False)
W = Vt[:1].T
if W[0, 0] < 0:
    W = -W  # Только выбор знака для читаемого вывода.
Z = Xc @ W
reconstructed = Z @ W.T + mean
error = np.sum((data - reconstructed) ** 2)

pca = PCA(n_components=1, svd_solver="full").fit(data)
np.testing.assert_allclose(pca.components_.T @ pca.components_, W @ W.T)
np.testing.assert_allclose(pca.inverse_transform(pca.transform(data)), reconstructed)
print(mean, Z.ravel())
print("error:", error, "variance ratio:", pca.explained_variance_ratio_[0])
print("sample variance:", pca.explained_variance_[0])
```

Среднее равно $(10;20)$, коды $(-2;0;0;2)$, ошибка — 2, доля дисперсии —
0,8. Библиотека возвращает дисперсию $8/3$, а не 8: это собственное
значение выборочной ковариации с делителем $n-1=3$. Среднее не было
потеряно и вернулось при `inverse_transform`.

### Whitening меняет масштаб компонент

Обычный PCA даёт некоррелированные координаты с дисперсиями
$\lambda_1,\ldots,\lambda_m$. При whitening каждую координату дополнительно
делят на её стандартное отклонение:

$$
Z_{\mathrm{white}}=Z\operatorname{diag}
(\lambda_1^{-1/2},\ldots,\lambda_m^{-1/2}).
$$

Теперь выборочная ковариация сохранённых ненулевых компонент единичная.
Это масштабирование, а не дополнительный выбор направлений. Оно меняет
евклидовы расстояния между кодами: направление с малой исходной
дисперсией получает такой же масштаб, как направление с большой.
Если малое направление преимущественно содержит шум, его влияние
усиливается. Для нулевой дисперсии приведённая формула не определена.

Справа облако стало примерно круглым, поскольку компоненты дополнительно
приведены к единичной дисперсии. При обычном PCA без whitening облако
повернулось бы к главным осям, но сохранило бы разные дисперсии вдоль них.

```python
white_pca = PCA(n_components=2, whiten=True, svd_solver="full").fit(data)
white_codes = white_pca.transform(data)
np.testing.assert_allclose(np.cov(white_codes, rowvar=False), np.eye(2))
np.testing.assert_allclose(white_pca.inverse_transform(white_codes), data)
print(np.round(white_codes, 6))
```

Обе компоненты сохранены, поэтому в последнем примере реконструкция
точная. Whitening не восстанавливает направления, которые ранее были отброшены.

### Алгоритм

```text
Вход: X размера n × d, требуемая размерность m
1. Оценить среднее μ только на train и вычислить Xc = X - μ.
2. Если масштабы несопоставимы, оценить scale на train и стандартизовать Xc.
3. Вычислить экономичное SVD: Xc = U Σ Vᵀ.
4. Взять W = V[:, :m] и вернуть Z = Xc W.
5. Для новых данных применить те же μ, scale и W.
```

Число компонент выбирают по ошибке реконструкции, накопленной доле
дисперсии и, если PCA входит в модель с учителем, по качеству всей модели
на валидации. Подбирать $m$ на тестовой выборке нельзя.

### Ограничения PCA

- Без стандартизации признак с крупными единицами измерения может определить
  всё решение. Стандартизовать автоматически тоже нельзя: абсолютная дисперсия
  иногда и есть полезный сигнал.
- PCA линейна. Данные на изогнутой низкоразмерной поверхности она может
  представить плохо даже при малой внутренней размерности.
- Знак каждого $w_j$ произволен: $w_j$ и $-w_j$ описывают одну компоненту.
- При близких собственных значениях отдельные направления нестабильны; устойчивым
  может быть только порождённое ими подпространство.
- PCA, обученная до train/validation split, переносит информацию из validation
  в признаки. Она должна находиться внутри pipeline.

## t-SNE: вероятности локального соседства

### Как расстояния становятся вероятностями

Для каждой точки $x_i$ t-SNE задаёт вероятности выбора соседа:

$$
p_{j|i}=
\frac{\exp\!\left(-\|x_i-x_j\|^2/(2\sigma_i^2)\right)}
{\sum_{k\ne i}\exp\!\left(-\|x_i-x_k\|^2/(2\sigma_i^2)\right)}.
$$

Сама точка не выбирается: $p_{i|i}=0$, а сумма остальных вероятностей
в строке равна 1. В плотной области даже небольшая ширина гауссова ядра
охватывает несколько соседей. В разреженной области для того же числа
соседей потребуется большая ширина. Поэтому один общий масштаб расстояний
для всех точек здесь не используется.

Ширина $\sigma_i$ подбирается отдельно для каждой точки так, чтобы энтропия
распределения соответствовала заданной perplexity:

$$
\operatorname{Perp}(P_i)=2^{H(P_i)}.
$$

Здесь $H(P_i)=-\sum_{j\ne i}p_{j|i}\log_2p_{j|i}$.
При равномерном выборе из $s$ соседей энтропия равна $\log_2s$, поэтому
perplexity равна $s$. При неодинаковых весах она остаётся непрерывной
мерой эффективного числа соседей.

Если три соседа имеют вероятности $(0{,}5,0{,}25,0{,}25)$, энтропия равна
$1{,}5$ бита, а perplexity — $2^{1.5}\approx2{,}83$. Её удобно понимать как
мягкий эффективный размер окрестности, но не как число кластеров.

Для $n$ точек верхняя граница perplexity равна $n-1$. Если ближайший
сосед единственный, при $\sigma_i\to0$ распределение сосредоточивается
на нём и perplexity стремится к 1. Если несколько соседей находятся
на одном минимальном расстоянии, нижняя достижимая граница выше.
Бинарный поиск ширины не может устранить такое совпадение расстояний.

В примере ниже четыре точки. Для каждой выбирается ширина, при которой
perplexity равна 2. Удобно искать $\beta_i=1/(2\sigma_i^2)$:
при увеличении $\beta_i$ вероятности сосредоточиваются на ближайших
точках и энтропия уменьшается. Вычитание минимального квадрата расстояния
в экспоненте не меняет нормированные вероятности и предотвращает
одновременное исчезновение всех весов при большом $\beta_i$.
В коде энтропия считается с натуральным логарифмом, поэтому её целевое
значение равно $\ln2$, а не одному биту; найденные вероятности те же.

```python
def gaussian_row(squared_distances, target_perplexity):
    distances = np.asarray(squared_distances, dtype=float)
    if not 1 < target_perplexity < len(distances):
        raise ValueError("Use an interior attainable perplexity")
    shifted = distances - distances.min()
    tied_minima = np.count_nonzero(shifted == 0)
    if target_perplexity <= tied_minima:
        raise ValueError("Nearest-neighbor ties make the target unattainable")
    target_entropy = np.log(target_perplexity)
    lower, upper, beta = 0.0, np.inf, 1.0
    for _ in range(100):
        weights = np.exp(-beta * shifted)
        probabilities = weights / weights.sum()
        entropy = np.log(weights.sum()) + beta * (probabilities @ shifted)
        if abs(entropy - target_entropy) < 1e-12:
            return probabilities, np.sqrt(1 / (2 * beta))
        if entropy > target_entropy:
            lower = beta
            beta = 2 * beta if np.isinf(upper) else (beta + upper) / 2
        else:
            upper = beta
            beta = (lower + beta) / 2
    raise RuntimeError("Entropy search did not converge")

points = np.array([[0, 0], [1, 0], [0, 2], [3, 2]], dtype=float)
distances2 = np.sum((points[:, None] - points[None, :]) ** 2, axis=2)
conditional = np.zeros((4, 4))
sigmas = np.empty(4)
for i in range(4):
    others = np.arange(4) != i
    conditional[i, others], sigmas[i] = gaussian_row(distances2[i, others], 2)
P = (conditional + conditional.T) / (2 * len(points))
np.testing.assert_allclose(conditional.sum(axis=1), 1)
np.testing.assert_allclose(P.sum(), 1)
print("sigmas:", np.round(sigmas, 6))
print("first row:", np.round(conditional[0], 6))
```

Квадраты расстояний от первой точки равны 1, 4 и 13. Получается
$\sigma_0\approx1{,}306677$ и вероятности приблизительно
$(0{,}691961;0{,}287437;0{,}020603)$: первый сосед получает наибольший
вес, третий почти исключается. Остальные строки калибруются независимо: $p_{j|i}$ не обязано
совпадать с $p_{i|j}$.

Условные вероятности симметризуют:

$$
p_{ij}=\frac{p_{j|i}+p_{i|j}}{2n}.
$$

Полученная матрица симметрична, $p_{ii}=0$ и
$\sum_{i\ne j}p_{ij}=1$. Сумма идёт по упорядоченным парам: вклад
$(i,j)$ и вклад $(j,i)$ учитываются отдельно. Делитель $2n$ следует
из суммы $n$ нормированных строк и их транспонированной копии.

### Размещение точек и градиент

На плоскости сходство задают распределением Стьюдента с тяжёлым хвостом:

$$
q_{ij}=
\frac{(1+\|y_i-y_j\|^2)^{-1}}
{\sum_{k\ne l}(1+\|y_k-y_l\|^2)^{-1}}.
$$

Здесь также $q_{ii}=0$ и сумма по упорядоченным парам равна 1.
У гауссова ядра сходство убывает экспоненциально с квадратом расстояния,
у этого ядра — как обратный квадрат на больших расстояниях. Поэтому
умеренно похожие объекты могут находиться на плоскости существенно дальше
друг от друга, сохраняя ненулевое сходство.

Это смягчает проблему скучивания, *crowding problem*. В пространстве
размерности $d$ объём шара растёт как $r^d$, а площадь круга — как $r^2$.
При большом $d$ вокруг точки может быть много соседей на сопоставимых
расстояниях. Если перенести их на плоскость, требуя сохранить все такие
расстояния, им не хватит места: часть точек придётся сдвинуть ближе,
чем допускает исходное соседство. Тяжёлый хвост ослабляет требование
к расстояниям за пределами ближайшей окрестности; он не делает
двумерную карту точным воспроизведением всей геометрии.

Координаты минимизируют

$$
KL(P\|Q)=\sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}.
$$

Если $p_{ij}$ велико, а $q_{ij}$ мало,
цена высока: настоящих соседей нельзя разлучать. Если далёкая пара случайно
оказалась рядом, её прямой вклад слабее. Однако нормировка $Q$ общая:
увеличение сходства одной пары уменьшает доли остальных. Поэтому t-SNE
старается сохранить локальные окрестности,
но не обещает правильных расстояний между «островами», их площади или
плотности.

Градиент для точки складывается из попарных вкладов $F_{ij}$:

$$
\begin{aligned}
\frac{\partial KL}{\partial y_i}&=4\sum_jF_{ij},\\
F_{ij}&=(p_{ij}-q_{ij})
\frac{y_i-y_j}{1+\|y_i-y_j\|^2}.
\end{aligned}
$$

При спуске знак $p_{ij}-q_{ij}>0$ тянет точки друг к другу.
Если $q_{ij}>p_{ij}$, вклад пары раздвигает их. Следующий код вычисляет
точную сумму для четырёх точек, без приближённого поиска соседей
и ускоренной оценки сил. Начальные координаты заданы явно; один малый
шаг должен уменьшить KL, но не обязан построить хорошую карту.

```python
def student_objective(coordinates, pair_probabilities):
    delta = coordinates[:, None] - coordinates[None, :]
    inverse = 1 / (1 + np.sum(delta ** 2, axis=2))
    np.fill_diagonal(inverse, 0)
    Q = inverse / inverse.sum()
    present = pair_probabilities > 0
    loss = np.sum(pair_probabilities[present] *
                  np.log(pair_probabilities[present] / Q[present]))
    gradient = 4 * np.sum(
        ((pair_probabilities - Q) * inverse)[:, :, None] * delta, axis=1)
    return loss, gradient, Q

Y = np.array([[-1, 0], [-0.2, 0.3], [0.2, -0.4], [1, 0.1]])
loss_before, gradient, Q = student_objective(Y, P)
Y_next = Y - 0.1 * gradient
loss_after, _, _ = student_objective(Y_next, P)
assert loss_after < loss_before
np.testing.assert_allclose(gradient.sum(axis=0), 0, atol=1e-14)
print("KL before/after:", loss_before, loss_after)
```

KL уменьшается приблизительно с 0,189394 до 0,179185. В этом примере
сделан только один шаг; критерий остановки для полноценного обучения
по такому изменению не выбирают.

Сумма градиентов равна нулю: перенос всей карты на один и тот же вектор
не меняет расстояний. Поворот и отражение также не меняют цель.
Ориентация осей и положение начала координат сами по себе ничего
не говорят о смысле объектов. Общий масштаб, в отличие от переноса,
входит в ядро и влияет на результат.

В начале обучения часто применяют *early exaggeration*: в силе притяжения
$p_{ij}$ временно умножают на коэффициент $\alpha>1$, сохраняя обычное
отталкивание $q_{ij}$. Это не тот же самый градиент, что у
$KL(\alpha P\|Q)$: такая подстановка усилила бы и часть, возникающую
из общей нормировки. После начальной фазы возвращают исходные $P$
и продолжают оптимизацию; число итераций и шаг остаются параметрами
оптимизатора, а не свойствами обнаруженных кластеров.

### Практический протокол t-SNE

```text
1. Удалить явный шум и привести признаки к осмысленному масштабу.
2. Для очень большого d сначала сократить размерность PCA, например до 30–100.
3. Запустить несколько perplexity, совместимых с n, а не одно значение.
4. Для каждого значения повторить несколько seeds и дождаться сходимости.
5. Сравнить k-NN в исходном пространстве и на карте.
6. Подписать рисунок: preprocessing, metric, perplexity, seed, iterations.
```

Если остров появился лишь при одном начальном состоянии, одного такого
результата недостаточно для вывода о данных. Повторения и просмотр
исходных соседей помогают отделить устойчивое наблюдение от случайной
укладки. Классический t-SNE оптимизирует координаты
конкретной выборки и не обучает явную функцию $f(x)$.

## UMAP: восстановление fuzzy-графа соседей

### Почему радиус окрестности меняется от точки к точке

Если соединять все пары в пределах одного радиуса, плотный участок
получит множество связей, а разреженный может распасться. В официальном
объяснении UMAP это показано на точках вдоль изогнутой линии.

![[00 Учебник/Assets/Figures/curated/pca-tsne-umap-2026-10-25/umap-open-cover.png]]

*Leland McInnes и участники проекта UMAP,
[How UMAP Works — Topological Data Analysis and Simplicial Complexes](https://umap-learn.readthedocs.io/en/latest/how_umap_works.html#topological-data-analysis-and-simplicial-complexes),
BSD-3-Clause. Исходный рисунок без изменений.*

Круги одного радиуса перекрываются на густо заселённых дугах, но оставляют
разрывы посередине, где точки расположены реже. Такие разрывы могут
отражать лишь плотность выборки, а не разрыв исходной поверхности.
Выбор ближайших соседей вместо одного абсолютного радиуса даёт больший
пространственный охват в разреженной области.

![[00 Учебник/Assets/Figures/curated/pca-tsne-umap-2026-10-25/umap-adaptive-cover.png]]

*Те же авторы,
[Adapting to Real World Data](https://umap-learn.readthedocs.io/en/latest/how_umap_works.html#adapting-to-real-world-data),
BSD-3-Clause. Исходный рисунок без изменений.*

Теперь круги в разреженном участке больше и связывают его с остальной
цепочкой. Это иллюстрация локального масштаба, а не буквальная операция
рисования кругов в алгоритме. UMAP хранит список соседей и числовые
веса рёбер; дальнейшая оптимизация работает с этим графом.

### Построение весов

UMAP разделяет задачу на построение локального графа и его низкоразмерную
укладку. Сначала для каждой точки находят ближайших соседей. Локальный
порог $\rho_i$ обеспечивает единичный вес связи с ближайшей точкой, а масштаб
$\sigma_i$ адаптируется к плотности. При обозначении
$d_{ij}=d(x_i,x_j)$ направленный вес ребра равен

$$
w_{i\to j}=\exp\left(
-\frac{\max(0,d_{ij}-\rho_i)}{\sigma_i}
\right).
$$

Эту формулу применяют только к найденным соседям; остальные направленные
веса равны нулю. При стандартном `local_connectivity=1` и различных
точках $\rho_i$ равно расстоянию до ближайшего соседа. Вычитание
$\rho_i$ оставляет для сравнения превышение над ближайшим расстоянием,
а не абсолютный разрыв от нуля. В частности, если все расстояния
велики, но различаются мало, ближайшая связь всё равно имеет вес 1.
Параметр не обеспечивает связность всего графа: у него могут остаться
несколько компонент.

Например, при $\rho_i=1$ и $\sigma_i=2$ сосед на расстоянии 1 получает вес 1,
на расстоянии 3 — $e^{-1}\approx0{,}368$, на расстоянии 5 —
$e^{-2}\approx0{,}135$. Один и тот же абсолютный разрыв в плотной и разреженной
областях получает разный смысл благодаря локальному $\sigma_i$.

Масштаб не выбирают произвольно. В `umap-learn` 0.5.8 при обычном
обучении список длины $K=\texttt{n\_neighbors}$ включает саму точку
с расстоянием 0. В калибровочной сумме она пропускается; по остальным
элементам бинарным поиском подбирают $\sigma_i$ так, чтобы

$$
\sum_{j\in N_i}\exp\left[
-\frac{\max(0,d_{ij}-\rho_i)}{\sigma_i}
\right]\approx\log_2K.
$$

Здесь $N_i$ — найденные соседи без самой точки. Эта сумма задаёт
локальный масштаб весов, но не является энтропией и не превращает
строку в распределение вероятностей. После объединения направлений
сумма весов обычно изменяется. Совпадения точек, несколько равных
ближайших расстояний и нижняя численная граница масштаба требуют
обработки в реализации; точное равенство достижимо не всегда.

Для списка расстояний $(0,1,2,4)$ получаем $K=4$, $\rho=1$ и уравнение
$1+e^{-1/\sigma}+e^{-3/\sigma}=2$. При обозначении
$t=e^{-1/\sigma}$ оно становится $t+t^3=1$.
Следующий пример решает исходное уравнение и сравнивает результат
с функцией `smooth_knn_dist` из `umap-learn`.

```python
from scipy.optimize import brentq
from umap.umap_ import smooth_knn_dist

neighbor_distances = np.array([0, 1, 2, 4], dtype=float)
rho = 1.0
sigma = brentq(lambda s: np.exp(-(neighbor_distances[1:] - rho) / s).sum() - 2,
              1e-6, 100)
directed_weights = np.exp(-(neighbor_distances[1:] - rho) / sigma)
reference_sigma, reference_rho = smooth_knn_dist(
    neighbor_distances[None].astype(np.float32), 4.0)
np.testing.assert_allclose(reference_rho, [rho])
np.testing.assert_allclose(reference_sigma, [sigma], atol=1e-4)
np.testing.assert_allclose(directed_weights.sum(), 2)
print("rho/sigma:", rho, sigma, "weights:", directed_weights)
```

Получаются $\sigma\approx2{,}616123$ и веса
$(1;0{,}682328;0{,}317672)$ с суммой 2. В отличие от предыдущего
примера с произвольно заданным $\sigma=2$, здесь масштаб найден
из калибровочного условия.

Два направленных отношения объединяются fuzzy union:

$$
w_{ij}=w_{i\to j}+w_{j\to i}-w_{i\to j}w_{j\to i}.
$$

Если веса равны 0,8 и 0,3, итоговая связь $0{,}8+0{,}3-0{,}24=0{,}86$:
сильного свидетельства хотя бы с одной стороны достаточно, но вес остаётся не
выше единицы.

Смысл формулы совпадает с вероятностью хотя бы одного из двух независимых
событий: $1-(1-a)(1-b)$. Здесь это выбранное правило объединения
нечётких связей, а не установленная статистическая независимость
измерений расстояния. Направления могут иметь разные веса потому,
что используют разные локальные масштабы.

![[00 Учебник/Assets/Figures/curated/pca-tsne-umap-2026-10-25/umap-fuzzy-graph.png]]

*Leland McInnes и участники проекта UMAP,
[Adapting to Real World Data — Graph with combined edge weights](https://umap-learn.readthedocs.io/en/latest/how_umap_works.html#adapting-to-real-world-data),
BSD-3-Clause. Исходный рисунок без изменений.*

В итоговом графе видна та же цепочка; у связей различается насыщенность.
Числа $w_{ij}$ выражают силу соседства, а не длину нарисованного ребра.
Граф разрежен, поэтому не требуется хранить все $n(n-1)$ сходств.

### Низкоразмерное сходство и попарная cross-entropy

В низкоразмерном представлении сходство моделируется функцией

$$
\tilde w_{ij}=\frac{1}{1+a\|y_i-y_j\|^{2b}},
$$

Для фиксированного графа двоичная cross-entropy по неупорядоченным парам равна

$$
\begin{aligned}
\mathcal L(Y)&=\sum_{i<j}\ell_{ij},\\
\ell_{ij}&=-w_{ij}\log\tilde w_{ij}\\
&\quad-(1-w_{ij})\log(1-\tilde w_{ij}).
\end{aligned}
$$

Первое слагаемое штрафует разрыв существующей связи, второе — сближение
несвязанных вершин. Например, при $w=0{,}8$ сходство $\tilde w=0{,}8$
даёт вклад около $0{,}5004$, а $\tilde w=0{,}2$ — $1{,}3322$.
Рёбра здесь не образуют одно распределение с общей суммой 1, как пары t-SNE:
каждая пара имеет своё сходство в диапазоне $[0,1]$.

Если рассматривать одну пару отдельно, минимум по $\tilde w$ достигается
при $\tilde w=w$. Одновременно удовлетворить всем парам на плоскости
обычно невозможно. При $a=b=1$ расстоянию $r$ соответствует
$\tilde w=1/(1+r^2)$, а вклад пары и его производная имеют вид

$$
\begin{aligned}
\ell(r)&=\log(1+r^2)-(1-w)\log r^2,\\
\ell'(r)&=\frac{2r}{1+r^2}-\frac{2(1-w)}r.
\end{aligned}
$$

При $w=0{,}8$ минимум находится в $r=0{,}5$.
Если раздвинуть точки до $r=2$, производная равна 0,6, и спуск
уменьшает расстояние. При $r=0{,}25$ производная отрицательна:
точки слишком близки относительно заданного веса.

```python
def pair_cross_entropy(distance, weight):
    similarity = 1 / (1 + distance ** 2)  # a = b = 1
    loss = -weight * np.log(similarity) - (1 - weight) * np.log1p(-similarity)
    derivative = 2 * distance / (1 + distance ** 2) - 2 * (1 - weight) / distance
    return similarity, loss, derivative

for r in [0.25, 0.5, 2.0]:
    print(r, pair_cross_entropy(r, 0.8))
```

Это расчёт полной попарной цели для объяснения притяжения
и отталкивания. Ниже отдельно разобрано, чем от него отличается
стандартная оптимизация UMAP.

Параметры $a,b$ определяют форму спада и подбираются численно по `min_dist`
и `spread`, а не обучаются отдельно для каждой пары. В официальном
[`find_ab_params`](https://umap-learn.readthedocs.io/en/latest/_modules/umap/umap_.html#find_ab_params)
кривая $1/(1+ar^{2b})$ приближается к функции, равной 1 при
$r<\mathrm{min\_dist}$ и
$\exp[-(r-\mathrm{min\_dist})/\mathrm{spread}]$ дальше.
Поэтому увеличение `min_dist` расширяет область почти полного сходства:
точки могут находиться дальше, не испытывая сильного притяжения. Это мягкая
форма целевой кривой, не жёсткий запрет меньших расстояний.

### Что меняет отрицательное семплирование

Полная сумма по всем парам содержит квадратичное число слагаемых.
Стандартная реализация планирует положительные обновления с частотой,
пропорциональной весу ребра. Для выбранного ребра $i\to j$ сближаются
обе вершины. Затем выбираются случайные отрицательные вершины;
от каждой из них отталкивается $i$, но сама отрицательная вершина
на этом обновлении не перемещается.

Полученная оценка градиента смещена относительно полной cross-entropy.
В разборе Damrich и Hamprecht, [§5, уравнения 7–12](https://arxiv.org/abs/2103.14608v2),
для упрощённой модели семплирования получен ожидаемый градиент

$$
\begin{aligned}
\mathbb E[g_i]=2\sum_j\bigg[&w_{ij}
\frac{\partial L^a_{ij}}{\partial y_i}\\
&+\frac{d_i m_-}{2n}
\frac{\partial L^r_{ij}}{\partial y_i}\bigg],
\end{aligned}
$$

где $d_i=\sum_jw_{ij}$ — взвешенная степень, $m_-$ — число отрицательных
выборок на положительное ребро, $L^a=-\log\tilde w$ и
$L^r=-\log(1-\tilde w)$. В градиенте полной суммы вместо
$d_i m_-/(2n)$ стоит $1-w_{ij}$. Общий множитель 2 связан с учётом
обоих направлений ребра и не меняет это расхождение.

Например, при $n=5$, $d_i=1{,}2$ и $m_-=2$ первый коэффициент
равен 0,24. Для отсутствующей связи $w_{ij}=0$ коэффициент полной
суммы равен 1. Частота отрицательных выборок меняет соотношение сил,
а не только точность приближения той же функции.

У исходного одностороннего отрицательного обновления ожидаемые силы
в общем случае даже не являются градиентом одной скалярной функции.
В статье также рассмотрена модификация, перемещающая обе вершины
отрицательной пары; её эффективную цель нельзя без оговорки приписать
стандартному алгоритму. В `umap-learn` дополнительно применяются
ограничение компонент обновления и стабилизирующее слагаемое 0,001
в отталкивании. Поэтому формула ожидания объясняет различие весов,
но не заменяет описание всех численных деталей реализации.

Основные параметры:

- `n_neighbors` задаёт масштаб локального графа. Малые значения подчёркивают
  мелкие окрестности; большие пытаются согласовать более широкую структуру.
- `min_dist` меняет кривую сходства и тем самым степень уплотнения групп.
  Это не гарантированная нижняя граница расстояния между точками.
- `metric` определяет исходную геометрию. Для векторных представлений текста
  косинусное расстояние может быть осмысленнее евклидова.
- `n_components` не обязан равняться двум: UMAP можно использовать как
  преобразование признаков, если вся модель проверяется на отложенных данных.

В отличие от классического t-SNE, обученный UMAP поддерживает `transform`
новых объектов. Повторное обучение с другой выборкой, начальным состоянием
или параметрами способно повернуть и перестроить карту.

При `transform` ищутся соседи нового объекта среди обучающих точек.
Их координаты дают начальное положение, после чего координаты новых
объектов уточняются относительно фиксированной обучающей карты.
Полного совместного переобучения старых и новых точек при этом нет.
Если новый объект находится вне распределения обучения, ближайшие
доступные соседи всё равно будут найдены: наличие координат не
доказывает, что такое положение надёжно.

| Метод | Цель и применение |
| --- | --- |
| PCA | Линейное сжатие с минимальной квадратичной ошибкой восстановления. Новые данные преобразуются сохранённой матрицей. Оси связаны с исходными признаками, но потерянные нелинейные зависимости не восстанавливаются. |
| t-SNE | Оптимизация KL между распределениями пар. Подходит для исследования локальных соседств данной выборки. Классический алгоритм не обучает преобразование новых объектов; площади и промежутки между группами нельзя читать как исходные расстояния. |
| UMAP | Разреженный взвешенный граф и его размещение с положительными и отрицательными обновлениями. Поддерживает приближённое размещение новых объектов. Геометрия карты зависит от масштаба соседства и соотношения сил; площадь группы не оценивает исходную плотность. |

### Диагностика, обязательная для любой карты

Численно оценить ложных соседей позволяет *trustworthiness*.
Пусть $r(i,j)$ — ранг объекта $j$ среди соседей $i$ в исходном
пространстве: ближайший имеет ранг 1. Обозначим через $U_k(i)$ тех,
кто попал в $k$ ближайших на карте, но не входил в исходные
$k$ ближайших. Метрика штрафует такие вторжения:

$$
\begin{aligned}
T(k)&=1-\frac{2S}{nk(2n-3k-1)},\\
S&=\sum_i\sum_{j\in U_k(i)}(r(i,j)-k).
\end{aligned}
$$

В реализации scikit-learn требуется $k<n/2$. Например, при $k=2$
объект с исходным рангом 3 даёт штраф 1, а с рангом 8 — штраф 6.
Случайное небольшое изменение порядка и перенос далёкого объекта
в ближайшее соседство наказываются по-разному. Ранг считается
в исходной метрике, поэтому смена исходного расстояния меняет
сам критерий оценки.

Trustworthiness проверяет вторжения, но не является полной проверкой
всех расстояний. Дополнительно можно считать долю сохранённых соседей
и разбирать потери исходного соседства. При разных $k$ измеряются
разные масштабы; ни один результат не доказывает наличия классов
или кластеров. Формула и ограничения приведены в
[документации scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.trustworthiness.html).

Для выбранных точек полезно открыть сами объекты из двух списков
соседей. Для текстов это могут быть похожие документы с разными темами,
для изображений — совпавшие фон или яркость вместо содержимого.
Число без просмотра примеров не объяснит, какое сходство сохранил метод.

Несколько начальных состояний и несколько масштабов соседства позволяют
проверить устойчивость наблюдений. Сравнивать координаты поэлементно
бессмысленно без учёта поворота и отражения; сравнивать соседства можно
непосредственно. Даже повторяющийся остров следует проверять в исходных
данных, а не объявлять установленным классом.

### Разделение обучающих и новых объектов

В следующем примере берётся каждое десятое изображение из встроенного
набора рукописных цифр. Это небольшой пример работы API, не сравнение
качества алгоритмов. Все 64 пиксельных признака измерены в одинаковых
единицах; отдельная стандартизация каждого пикселя здесь не добавляется.
На обучающих 140 изображениях PCA сохраняет 20 компонент. Оставшиеся
40 изображений не участвуют ни в оценке среднего, ни в выборе направлений.

```python
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE, trustworthiness
from umap import UMAP

digits = load_digits().data[::10]
train_digits, new_digits = digits[:140], digits[140:]
preprocessor = PCA(n_components=20, svd_solver="full").fit(train_digits)
train_codes = preprocessor.transform(train_digits)
new_codes = preprocessor.transform(new_digits)

tsne = TSNE(n_components=2, perplexity=15, init="pca",
            learning_rate="auto", max_iter=750, method="exact", random_state=7)
tsne_coordinates = tsne.fit_transform(train_codes)
mapper = UMAP(n_neighbors=15, min_dist=0.1, n_components=2,
              n_epochs=150, random_state=7, transform_seed=7, n_jobs=1)
umap_coordinates = mapper.fit_transform(train_codes)
training_snapshot = mapper.embedding_.copy()
new_coordinates = mapper.transform(new_codes)
np.testing.assert_array_equal(mapper.embedding_, training_snapshot)
assert new_coordinates.shape == (40, 2)
assert np.isfinite(new_coordinates).all()
print("t-SNE neighbors:", trustworthiness(train_codes, tsne_coordinates, n_neighbors=5))
print("UMAP neighbors:", trustworthiness(train_codes, umap_coordinates, n_neighbors=5))
```

Обе оценки соседства здесь относятся к уже сокращённым 20-мерным
данным. Чтобы проверить потери всего преобразования, исходными данными
для метрики надо передать 64 пикселя. Для новых объектов UMAP проверена
форма результата и неизменность обучающей карты; это ещё не оценка
качества расположения новых цифр. У классического `TSNE` метода
`transform` нет, поэтому такой же вызов к нему не выполняется.

Если после PCA или UMAP обучается классификатор, весь выбор
преобразования и его параметров проводят внутри обучающих частей
кросс-валидации. Даже преобразование без меток, обученное до разделения
выборки, использует информацию о валидационных объектах. Раскрашивание
готовой карты по меткам допустимо, но передача меток в supervised UMAP
уже меняет задачу и должна быть явно указана.
