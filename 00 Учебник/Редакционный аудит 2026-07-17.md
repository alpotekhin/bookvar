## Обнаруженные короткие заглушки

Автоматический поиск разделов с менее чем восемью содержательными строками
выделил следующий приоритетный backlog. Служебные разделы `Источники`,
`Связанные заметки`, выводы и списки ошибок сами по себе дефектом не считаются.

| Модуль | Разделы, требующие развёртывания |
|---|---|
| Sampling | Top-k, Top-p |
| Pre-training | Deduplication, Mixture, Chinchilla/inference-optimal training |
| Distributed training | Pipeline bubbles, mixed precision |
| Retrieval | Sparse retrieval, hybrid search |
| RAG | Ingestion |
| Multimodality | LLaVA-подобная схема, cross-attention и resampler |

Для каждого такого раздела нужен не механический объём, а полный минимальный
контур: задача → механизм → пример → ограничения → источник → связь с системой.

Структурный gate не равен финальной приёмке. После переработки остальных глав
нужен единый проход по языку, captions, корректности источников и визуальному
ритму всего учебника.
