# Визуальный язык

- синий: поток представлений;
- зелёный: attention и маршрутизация;
- оранжевый: FFN/эксперты;
- фиолетовый: обучение и post-training;
- серый: память, cache и инфраструктура.

Цвет всегда дублируется текстовой подписью. Схема должна отвечать на один
конкретный вопрос, а не пытаться показать всю модель сразу.
