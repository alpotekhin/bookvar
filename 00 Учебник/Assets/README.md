# Визуальный язык

> [!note] Архивная палитра собственных схем
> Эта договорённость относится к ранним схемам проекта, а не к изображениям
> из курсов и статей. Для оригинального рисунка смысл цвета определяется
> легендой и подписью автора. Ниже сохранена прежняя палитра; применять её
> ко всему учебнику или перекрашивать под неё исходные рисунки не нужно.

- синий: поток представлений;
- зелёный: attention и маршрутизация;
- оранжевый: FFN/эксперты;
- фиолетовый: обучение и post-training;
- серый: память, cache и инфраструктура.

Цвет всегда дублируется текстовой подписью. Схема должна отвечать на один
конкретный вопрос, а не пытаться показать всю модель сразу.
