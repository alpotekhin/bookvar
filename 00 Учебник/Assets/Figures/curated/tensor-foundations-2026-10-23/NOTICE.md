# NumPy tensor illustrations

Five complete originals from NumPy 2.3, pinned to upstream commit
`0532af47d6a815298b7841de00bdbc547104b237` (v2.3.0).
No redraw, crop, resampling, relabeling, or translation.

- NumPy Developers: Broadcasting, Figures 2–4. Original SVGs are used instead
  of the low-resolution PNGs displayed by the documentation website.
- Jay Alammar / NumPy Developers: the two images in “Transposing and reshaping
  a matrix”. The source document explicitly credits Jay Alammar.
  The published PNGs match the pinned repository originals byte-for-byte.

Source pages:

- https://numpy.org/doc/2.3/user/basics.broadcasting.html
- https://numpy.org/doc/2.3/user/absolute_beginners.html#transposing-and-reshaping-a-matrix

NumPy's BSD-3-Clause copyright notice, conditions, and disclaimer are retained
in `05 Источники/Originals/numpy-tensors-2.3/LICENSE.txt` and shipped as
`site/public/licenses/numpy-v2.3.0-BSD-3-Clause.txt`.
The two original RST documents are retained alongside the license.

`assets.json` records exact source URLs, authors, SHA-256 values, source
documents, and destination chapter. The central asset registry has the same
records. Each image file is itself the retained unmodified source; no second
local copy is needed.
