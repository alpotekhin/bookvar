# MoCo diagram

Kaiming He, Haoqi Fan, Yuxin Wu, Saining Xie and Ross Girshick,
*Momentum Contrast for Unsupervised Visual Representation Learning*, Figure 1.
https://arxiv.org/abs/1911.05722v3

The complete diagram is extracted from the native PDF at 400 dpi. All arrows,
input/output labels and encoder boxes remain; only the surrounding paper body
is excluded. No redrawing, translated labels or bitmap enlargement.

The same diagram is explicitly embedded in the authors' repository README:
https://github.com/facebookresearch/moco/blob/aea97d4b6eb091846590506784f6809f4f4d79bd/README.md
That archived project release uses CC BY-NC 4.0:
https://github.com/facebookresearch/moco/blob/aea97d4b6eb091846590506784f6809f4f4d79bd/LICENSE
The published PNG is preserved as permission evidence and visually compared
with the native PDF diagram. This basis is not extended to other paper figures
or to extensive reproduction of the paper's prose.

The later code snapshot 132aea9 uses a formal MIT LICENSE and MIT source
headers, despite its README retaining the older CC license wording. Code and
diagram rights are therefore documented separately, with both notices retained.

Exact hashes, native page/crop/dpi and permission assets are in assets.json.
The asset validator rerenders and compares PNG bytes. The comparison image of
SimCLR is reused from its existing CC BY 4.0 registry entry; it is not copied
into this directory or relabelled as a MoCo figure.
