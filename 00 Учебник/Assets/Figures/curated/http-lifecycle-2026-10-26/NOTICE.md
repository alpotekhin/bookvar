# Original vLLM engine-interface illustration

vLLM contributors, Architecture Overview, v0.11.0 documentation at commit
`b8b302cde434df8c9289a2b465406b47ebab1c2d`.

The complete original PNG is copied unchanged from
`docs/assets/design/arch_overview/llm_engine.excalidraw.png`.
Source and license URLs, complete page/license snapshots, original/copied
hashes and reader attribution are recorded in `assets.json` and the global
registry. Apache-2.0 license text is also served at
`/licenses/vllm-b8b302cd-Apache-2.0.txt`.

No crop, redraw, translation, resampling or recompression. The figure uses
the LLMEngine/AsyncLLMEngine names of this pinned overview; it is not evidence
for current V1 process placement. Both the entrypoint and engine originals
were compared; the engine figure was selected because it also separates
input processing, scheduling, execution and output processing.
