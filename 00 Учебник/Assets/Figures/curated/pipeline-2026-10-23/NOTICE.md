# Original pipeline illustration

Source commit: c93890dd4b22356ee18ed9b863e6f2d0909729bc. It is copied byte-for-byte; only the filename changed. The source figure labels layers, unlike the microbatch labels in the following schedules.

The pinned source README declares Apache-2.0. Its complete license text is distributed at [/licenses/ultrascale-Apache-2.0.txt](/licenses/ultrascale-Apache-2.0.txt). The exact source URL, file hash, pinned article snapshot and license declaration are recorded in assets.json and the central asset registry. Existing archived HTML/README in tensor-sequence-2026-10-23 are reused, not downloaded or duplicated again.

No license from this Playbook is assigned to third-party Zero Bubble paper figures. The separately imported author-published Space figures have their own pinned Apache declaration in zero-bubble-2026-10-23/assets.json and NOTICE.md; it is not a license for the paper PDF.
