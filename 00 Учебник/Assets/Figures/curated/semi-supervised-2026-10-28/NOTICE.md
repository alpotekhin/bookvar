# Semi-supervised learning: original illustrations

The complete FixMatch white-background diagram comes from Google Research's
repository at d4985a158065947dba803e626ee9a6721709c570, file
`media/FixMatch diagram white.png`. Copyright Google LLC and contributors;
Apache-2.0. License retained in the source packet and public license copy.
The paper's arXiv nonexclusive distribution license is not substituted for
the repository's explicit permission.

The two complete circles PNGs come from the scikit-learn developers' official
“Label Propagation circles: Learning a complex structure” documentation example,
BSD-3-Clause. Original source, page and images archived; BSD copyright and terms
retained in `/licenses/semi-supervised-sklearn-BSD-3-Clause.txt`.

The two circles figures are byte-identical source copies. FixMatch's same
diagram is extracted from native PDF p.2 at 400 dpi, box
`[800,375,2650,1075]` on a 3400×4400 page, giving 1850×700 pixels. All
branches, labels, bars and margins are retained; page body/caption omitted.
Its drawing, separately released in the author repository under Apache-2.0,
was visually compared with the archived repository PNG. This permission is
not applied to the rest of the arXiv paper. No bitmap upscaling, redrawing,
relabeling, translation or model-generated illustration.
The 400×400 circles images are the original published resolution, not
claimed to be high-resolution rerenders. Captions identify the source's
actual LabelSpreading API and the hard-clamped worked example separately.

The threshold-example image is not imported: source code computes its label
count using the full 569-sample size while fitting a smaller CV training fold.
The source note records this finding instead of copying a misleading count.
