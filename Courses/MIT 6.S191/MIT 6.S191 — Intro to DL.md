## Что такое Deep Learning

Deep Learning — подмножество Machine Learning, которое использует **нейронные сети с множеством слоёв** для обучения иерархическим представлениям данных.

```
AI ⊃ Machine Learning ⊃ Deep Learning
```

**Почему "deep"?** — множество слоёв (layers). Каждый слой извлекает всё более абстрактные признаки: пиксели → края → формы → объекты → сцены.

**Почему сейчас?** Три фактора совпали:
1. **Данные** — интернет создал огромные датасеты
2. **Compute** — GPU дали необходимую вычислительную мощность
3. **Алгоритмы** — backpropagation + modern architectures

## Perceptron: один нейрон

Базовый элемент любой нейронной сети:

```
x₁ ──┐
x₂ ──┼──→ [Σ w_i·x_i + b] → [activation σ] → output
x₃ ──┘
```

**Математически:**

```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = wᵀx + b
ŷ = σ(z)
```

где:
- **w** — веса (weights), определяют важность каждого входа
- **b** — bias, сдвиг
- **σ** — функция активации (нелинейность)

### Функции активации

Без нелинейности любая глубокая сеть эквивалентна одному линейному слою.

| Функция | Формула | Использование |
|---------|---------|--------------|
| Sigmoid | σ(z) = 1/(1+e^(-z)) | Исторический, выход 0-1 |
| Tanh | tanh(z) = (e^z-e^(-z))/(e^z+e^(-z)) | Выход -1 до 1 |
| ReLU | max(0, z) | Стандарт для hidden layers |
| GELU | z·Φ(z) | Transformers (BERT, GPT) |
| SiLU/Swish | z·σ(z) | Современные LLM (LLaMA) |

**ReLU** доминирует благодаря простоте и отсутствию vanishing gradient для положительных значений. **GELU/SiLU** — плавные аналоги для Transformer-архитектур.

## Многослойная сеть (MLP)

Нейроны объединяются в **слои**, слои — в **сети**:

```
Input Layer    Hidden Layer 1    Hidden Layer 2    Output Layer
  x₁ ────────→ h₁⁽¹⁾ ─────────→ h₁⁽²⁾ ─────────→ ŷ₁
  x₂ ────────→ h₂⁽¹⁾ ─────────→ h₂⁽²⁾ ─────────→ ŷ₂
  x₃ ────────→ h₃⁽¹⁾ ─────────→ h₃⁽²⁾
  x₄ ────────→ h₄⁽¹⁾
```

**Forward pass:**

```
h⁽¹⁾ = σ(W⁽¹⁾x + b⁽¹⁾)
h⁽²⁾ = σ(W⁽²⁾h⁽¹⁾ + b⁽²⁾)
ŷ = softmax(W⁽³⁾h⁽²⁾ + b⁽³⁾)
```

Каждый слой — линейное преобразование + нелинейность. Depth (глубина) позволяет строить иерархические представления.

## Loss Functions

Loss function измеряет, насколько предсказания модели далеки от правильных ответов.

### Cross-Entropy Loss (классификация)

```
L = -Σᵢ yᵢ · log(ŷᵢ)
```

Для бинарной классификации:
```
L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
```

### MSE (регрессия)

```
L = (1/n) Σᵢ (yᵢ - ŷᵢ)²
```

### Общая задача оптимизации

```
θ* = argmin_θ (1/n) Σᵢ L(f(xᵢ; θ), yᵢ)
```

Найти параметры θ, минимизирующие среднюю loss на обучающей выборке.

## Backpropagation

Алгоритм вычисления градиентов ∂L/∂w для всех весов сети. Основан на **chain rule**:

```
∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂h⁽²⁾ · ∂h⁽²⁾/∂h⁽¹⁾ · ∂h⁽¹⁾/∂w₁
```

**Алгоритм:**
1. **Forward pass** — вычисляем все промежуточные значения и loss
2. **Backward pass** — распространяем градиенты от loss к входам
3. **Update** — обновляем веса: w ← w - η · ∂L/∂w

### Vanishing / Exploding Gradients

При глубоких сетях градиенты могут:
- **Затухать** (vanishing) — если множители < 1, градиент экспоненциально уменьшается
- **Взрываться** (exploding) — если множители > 1, градиент растёт

**Решения:**
- ReLU (нет затухания для положительных значений)
- Residual connections (skip connections): h = F(x) + x
- [[Layer Normalization]]
- Gradient clipping (для exploding gradients)

## Оптимизация

### Stochastic Gradient Descent (SGD)

```
θ ← θ - η · ∇L(θ; x_batch)
```

Вместо полного датасета используем mini-batch (32-512 примеров). Быстрее и обеспечивает regularization через шум.

### Adam (Adaptive Moment Estimation)

Стандарт для deep learning. Комбинирует:
- **Momentum** — экспоненциальное среднее градиентов (направление)
- **RMSProp** — экспоненциальное среднее квадратов градиентов (масштаб)

```
m_t = β₁·m_{t-1} + (1-β₁)·g_t          # first moment
v_t = β₂·v_{t-1} + (1-β₂)·g_t²         # second moment
θ_t = θ_{t-1} - η · m̂_t / (√v̂_t + ε)  # update
```

Типичные значения: β₁=0.9, β₂=0.999, η=3e-4.

### Learning Rate Schedule

Learning rate — самый важный гиперпараметр. Стратегии:

- **Warmup** — начинаем с маленького lr, постепенно увеличиваем
- **Cosine decay** — плавное уменьшение по косинусу
- **Warmup + cosine** — стандарт для LLM тренировки

```
     lr
     │    /‾‾‾‾\
     │   /       \
     │  /          \___
     │ /                \___
     │/                      \___
     └────────────────────────── steps
     warmup    cosine decay
```

## Regularization

Проблема **overfitting** — модель запоминает тренировочные данные вместо обучения паттернам.

### Dropout

Во время тренировки случайно "выключаем" нейроны с вероятностью p:

```
h_dropped = h * mask    # mask ∈ {0, 1}, P(mask=0) = p
h_test = h * (1-p)      # при inference масштабируем
```

Типичные p: 0.1-0.5. Это заставляет сеть быть "робастной" — не полагаться на отдельные нейроны.

### Другие методы

- **Weight decay** (L2 regularization): L_total = L + λ||w||²
- **Data augmentation** — увеличение данных трансформациями
- **Early stopping** — останавливаем тренировку, когда val loss растёт
- **Batch Normalization / [[Layer Normalization]]**

## Universal Approximation Theorem

**Теорема:** нейронная сеть с одним hidden layer достаточной ширины может аппроксимировать любую непрерывную функцию на компактном множестве.

**Важно:** теорема говорит о *существовании* такой сети, но не о том, что SGD её найдёт. На практике глубокие сети работают лучше широких — иерархические представления эффективнее.

## От MLP к современным архитектурам

MLP — основа, но у него ограничения:
- Не учитывает **порядок** входов (нет notion of sequence)
- Не учитывает **пространственную структуру** (нет locality)
- Квадратичный рост параметров с размером входа

Отсюда специализированные архитектуры:
- **CNN** — для пространственных данных (изображения) → [[MIT 6.S191 — Computer Vision]]
- **RNN/LSTM** — для последовательностей → [[MIT 6.S191 — Sequence Modeling]]
- **Transformer** — универсальная архитектура на [[Attention Mechanism]]

## Ключевые выводы

1. **Нейрон** = линейное преобразование + нелинейность
2. **Backpropagation** + **SGD/Adam** — механизм обучения
3. **Depth** позволяет выучить иерархические представления
4. **Regularization** (dropout, weight decay) борется с overfitting
5. Всё начинается с MLP, но специализированные архитектуры эффективнее
